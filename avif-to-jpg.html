AVIF to JPG 변환기

<img> 태그로 AVIF를 디코딩해 원본 해상도 그대로 Canvas에 그린 뒤, canvas.toBlob()으로 원하는 형식의 이미지 파일을 다시 인코딩합니다. JPG는 알파 채널을 지원하지 않는 포맷이라, 투명 배경이 있는 AVIF를 아무 처리 없이 그대로 JPG로 인코딩하면 브라우저가 투명 영역을 검은색으로 채워버리는 경우가 있는데(Canvas의 기본 픽셀은 완전 투명한 검정이고 JPEG 인코딩 시 알파값이 버려지면서 RGB(0,0,0)만 남기 때문), 이 도구는 JPG로 변환할 때만 그리기 전에 캔버스를 흰색으로 미리 채워 배경이 검게 나오는 문제를 방지합니다. PNG·WebP는 알파 채널을 지원하므로 이 처리 없이도 AVIF의 투명 영역이 그대로 유지됩니다. AVIF는 AV1 비디오 코덱 기반 차세대 이미지 형식으로 동일 품질에서 JPG보다 약 50%, WebP보다 약 20% 작은 파일 크기를 냅니다. 브라우저에서 직접 변환하므로 파일이 서버에 업로드되지 않습니다.

자주 묻는 질문

AVIF 형식이란?

AV1 Image File Format의 약자로, AV1 비디오 코덱의 인트라 프레임 압축 기술을 이미지에 적용한 차세대 형식입니다. WebP보다 더 높은 압축률과 품질을 제공합니다.

모든 브라우저에서 AVIF 변환이 가능한가요?

Chrome 85+, Firefox 93+, Safari 16+에서 지원됩니다. 브라우저가 AVIF 디코딩을 지원하지 않으면 이미지 로드 자체가 실패해 "변환 실패" 상태로 표시됩니다.

AVIF를 JPG로 변환할 때 투명 배경은 어떻게 되나요?

흰색 배경으로 채워집니다. JPG는 알파 채널을 지원하지 않으므로, 투명 영역이 있는 AVIF를 아무 처리 없이 JPG로 인코딩하면 브라우저가 기본적으로 검은색을 남기는 경우가 있습니다. 이 도구는 JPG 출력 시에만 미리 흰색으로 캔버스를 채운 뒤 이미지를 그려 이 문제를 방지합니다.

AVIF를 PNG나 WebP로 변환하면 투명도가 유지되나요?

예. PNG와 WebP 모두 알파 채널을 지원하므로 별도 처리 없이도 AVIF의 투명 영역이 그대로 유지됩니다. JPG로 변환할 때만 흰색으로 대체됩니다.

품질 슬라이더는 모든 출력 형식에 적용되나요?

아니요. 품질 값은 손실 압축 형식인 JPG와 WebP에만 영향을 줍니다. PNG는 무손실 압축 형식이라 브라우저가 품질 값을 무시하므로, PNG를 선택한 상태에서는 슬라이더를 조정해도 결과 파일에 변화가 없습니다.

파일이 서버에 업로드되나요?

아니요. 모든 디코딩·인코딩이 브라우저의 Canvas API를 사용해 로컬에서 처리됩니다.

여러 파일을 한 번에 변환할 수 있나요?

예, 여러 AVIF 파일을 선택하거나 드래그하면 각 파일이 독립적으로 순차 변환되어 개별 다운로드 링크가 생성됩니다.

변환 후 원본 해상도가 유지되나요?

예, 캔버스 크기를 img.naturalWidth/naturalHeight로 맞춰 그리므로 원본 해상도 그대로 변환됩니다.
