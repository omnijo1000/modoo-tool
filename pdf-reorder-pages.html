PDF 페이지 순서 변경

PDF의 페이지 순서는 파일 내부의 페이지 트리(Page Tree) 배열 순서로 결정됩니다. 이 도구는 pdf-lib로 원본 PDF의 각 페이지를 개별 객체로 복사한 뒤, 사용자가 지정한 순서대로 새 PDF 문서를 재조립합니다. 스캔한 문서의 페이지가 뒤섞였거나, 계약서에서 특정 조항 페이지를 삭제해야 하거나, 여러 보고서를 합친 뒤 순서를 정리할 때 유용합니다. 페이지를 드래그해 위치를 바꾸거나 × 버튼으로 삭제한 뒤 저장하면, 텍스트·이미지 등 페이지 내용은 그대로 유지된 채 순서와 구성만 바뀐 새 PDF가 만들어집니다.

자주 묻는 질문

특정 페이지를 삭제할 수 있나요?

네, 각 페이지 카드의 × 버튼을 클릭하면 해당 페이지가 목록에서 제거됩니다. 저장 버튼을 누르기 전까지는 실제 파일이 바뀌지 않으므로 여러 번 삭제·복구를 시도해봐도 안전합니다.

파일이 서버로 전송되나요?

아니요. pdf-lib 라이브러리가 브라우저 메모리 안에서 PDF를 직접 읽고 재조립하며, 파일이 외부로 전송되지 않습니다.

순서를 원래대로 되돌릴 수 있나요?

네, 저장하기 전까지는 '초기화' 버튼으로 원본 순서로 즉시 복원할 수 있습니다. 단, 이미 저장·다운로드한 파일은 되돌릴 수 없으니 원본 PDF를 따로 보관해 두는 것이 안전합니다.

페이지 수 제한이 있나요?

정해진 상한은 없지만, 모든 페이지가 브라우저 메모리에 올라가는 방식이라 수백 페이지 이상의 대용량 PDF는 기기 성능에 따라 로딩이 느려지거나 멈출 수 있습니다.

모바일 드래그가 지원되나요?

브라우저의 네이티브 드래그 앤 드롭 API를 사용하기 때문에 데스크톱에서 가장 안정적으로 동작합니다. 모바일 브라우저는 터치 기반 드래그 이벤트 지원이 기기·브라우저마다 달라 정상 동작하지 않을 수 있습니다.

PDF 내용이 변경되나요?

아니요. 각 페이지는 pdf-lib의 copyPages로 원본 그대로 복사되므로 텍스트, 이미지, 폰트, 링크 등 페이지 내용 자체는 전혀 손상되지 않습니다. 바뀌는 것은 페이지가 배열되는 순서와 포함 여부뿐입니다.

암호화된 PDF도 처리할 수 있나요?

아니요. 열람 암호가 걸린 PDF는 pdf-lib가 파일을 열 수 없어 처리되지 않습니다. PDF 암호 해제 도구로 먼저 잠금을 풀어야 합니다.

처리 속도는 어떤가요?

페이지 개수와 각 페이지에 포함된 이미지 용량에 좌우됩니다. 텍스트 위주의 수십 페이지 문서는 1~2초 안에 끝나지만, 고해상도 이미지가 많은 PDF는 저장 시 수 초가 걸릴 수 있습니다.
