이력서 템플릿 생성기

이 도구는 입력한 이름·목표 직무·경력·기술·학력을 【프로필 요약】【핵심 기술】【경력사항】【학력】 4개 섹션 아래 순서대로 배치하는 방식으로 동작하며, 대부분의 문장은 입력한 텍스트가 그대로 들어갑니다. 다만 프로필 요약 섹션의 한 문장("~로 ~ 전문성 보유.")만은 도구가 자동으로 만들어 붙이는데, 이 문장은 화면 표시 언어와 무관하게 항상 한국어 문법으로 고정돼 있어 영어·중국어·일본어 화면에서 생성해도 이 한 문장만 한국어로 섞여 나옵니다. 또한 폼에 있는 '이력서 언어' 드롭다운은 실제 생성 로직에서 값을 읽지 않으며, 이력서가 어떤 언어로 만들어지는지는 페이지 우측 상단 🌐 버튼으로 전환한 현재 화면 언어를 따릅니다.

자주 묻는 질문

폼에 있는 '이력서 언어' 드롭다운에서 English를 선택하면 영문 이력서가 나오나요?

아니요. 이 드롭다운의 선택값은 실제 이력서 생성 함수에서 읽어오지 않습니다. 이력서 언어는 이 드롭다운이 아니라 페이지 우측 상단의 🌐 언어 전환 버튼으로 바뀌는 현재 화면 언어에 따라 결정됩니다.

프로필 요약 문장은 화면 언어에 맞춰 나오나요?

아니요. "[경력 수준] [직무]로 [기술1, 기술2, 기술3] 전문성 보유." 형태의 이 한 문장은 화면 언어와 무관하게 항상 한국어 문법으로 고정돼 조합됩니다. 영어나 중국어, 일본어 화면에서 생성해도 이 요약 문장만은 한국어로 섞여 나오므로, 다른 언어로 이력서를 만들 때는 이 문장을 직접 새로 써야 합니다.

이름이나 목표 직무를 비워두면 어떻게 표시되나요?

[이름], [직무] 같은 대괄호 placeholder 텍스트가 대신 들어갑니다. 이 placeholder 역시 화면 언어와 무관하게 한국어로 고정돼 있으므로, 반드시 직접 입력하고 생성하는 것이 좋습니다.

핵심 기술 스택에 입력한 값은 이력서 어디에 쓰이나요?

입력한 기술 목록 전체는 【핵심 기술】 섹션에 쉼표 구분 그대로 나열됩니다. 반면 프로필 요약 문장에는 쉼표로 나눈 목록 중 앞의 3개만(slice(0,3)) 골라 인용되므로, 4번째 이후 기술은 요약 문장에는 등장하지 않습니다.

경력사항이나 학력 칸을 비워두면 이력서에서 어떻게 되나요?

이름·목표 직무와 달리 경력사항·학력·기술 스택은 비워두면 placeholder 없이 해당 섹션 전체가 결과에서 통째로 빠집니다. 이력서에 학력 섹션이 아예 보이지 않는다면 학력 칸이 비어 있었기 때문입니다.

STAR 기법(상황-과제-행동-결과)을 이 도구가 자동으로 적용해주나요?

아니요. 이 도구는 '주요 경력사항' 칸에 입력한 텍스트를 그대로 【경력사항】 섹션에 옮겨 적을 뿐, STAR 구조로 문장을 재구성하거나 다듬어주지 않습니다. STAR 기법으로 서술하고 싶다면 입력 단계에서 직접 그 구조에 맞춰 작성해야 합니다.

이 도구가 입력한 문장을 다듬거나 재구성해주나요?

프로필 요약의 고정 문장 한 줄을 제외하면, 나머지는 모두 사용자가 입력한 텍스트를 섹션 제목 아래 그대로 옮겨 붙이는 것뿐입니다. 문장 표현을 다듬거나 어색한 부분을 고쳐주는 기능은 없습니다.

생성된 이력서를 그대로 제출해도 될까요?

대부분의 내용이 입력한 텍스트 그대로이므로 오탈자나 표현은 직접 다시 확인해야 하며, 특히 비한국어 화면에서 생성했다면 프로필 요약 문장에 한국어가 섞여 있지 않은지 반드시 확인한 뒤 다시 작성해서 사용하는 것을 권장합니다.
