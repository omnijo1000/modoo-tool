이미지 크기 확인기

이미지 파일의 가로(너비), 세로(높이) 픽셀 크기, 종횡비, 파일 크기, 포맷 정보를 빠르게 확인합니다. 종횡비는 유클리드 호제법(GCD)으로 너비·높이의 최대공약수를 구해 1920×1080 → 16:9처럼 가장 단순한 정수비로 약분해 표시합니다. JPG, PNG, WebP, GIF, SVG, AVIF 등 다양한 이미지 형식을 지원하며 여러 파일을 한 번에 드래그&드롭으로 확인할 수 있습니다. 파일이 서버에 업로드되지 않아 개인정보가 보호됩니다.

자주 묻는 질문

어떤 이미지 형식을 지원하나요?

JPG, PNG, GIF, WebP, AVIF, BMP, SVG 등 브라우저가 지원하는 모든 이미지 형식을 지원합니다.

여러 이미지를 한 번에 확인할 수 있나요?

예, 여러 파일을 선택하거나 드래그&드롭하면 동시에 크기 정보가 표시됩니다. 그중 손상되었거나 브라우저가 디코딩할 수 없는 파일이 섞여 있어도 해당 파일에는 오류 표시만 뜨고 나머지 파일은 정상적으로 계속 처리됩니다.

파일이 서버에 업로드되나요?

아니요. 모든 처리가 브라우저에서 직접 이루어지며 파일이 서버로 전송되지 않습니다.

종횡비가 무엇인가요?

이미지의 너비와 높이의 비율입니다. 예: 1920×1080은 16:9 비율입니다.

총 픽셀 수는 어떻게 계산되나요?

너비 × 높이로 계산됩니다. 예: 1920×1080 = 2,073,600 픽셀 = 약 2.1MP.

SVG 이미지도 크기를 확인할 수 있나요?

SVG는 벡터 형식이라 픽셀 크기가 viewBox 또는 width/height 속성에 의존합니다. 둘 다 없는 SVG는 브라우저가 CSS 대체 크기 규칙에 따라 기본값(보통 300×150)으로 표시하므로, 표시된 크기가 디자인 의도와 다를 수 있습니다.

AVIF 이미지도 확인 가능한가요?

예, Chrome 85+, Firefox 93+, Safari 16+ 이상의 브라우저에서 AVIF 크기 확인이 가능합니다.

소셜 미디어 이미지 크기 기준이 있나요?

Facebook/Instagram: 1080×1080(정사각형), Twitter: 1200×675(16:9), YouTube: 1280×720(16:9), LinkedIn: 1200×627이 권장 사이즈입니다.
