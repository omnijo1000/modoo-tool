텍스트 암호화·복호화 도구

텍스트를 AES-256-GCM, Caesar, ROT13, Vigenere 방식으로 암호화하거나, 같은 페이지의 '복호화' 탭에서 다시 원문으로 되돌립니다. AES-256-GCM은 Web Crypto API로 비밀번호에서 PBKDF2(SHA-256, 10만 회 반복)로 256비트 키를 유도한 뒤, 매번 새로 생성한 16바이트 salt·12바이트 IV를 암호문 앞에 이어붙여 base64(salt + iv + ciphertext) 형태로 출력합니다 — 서버로 데이터가 전송되지 않습니다. Caesar와 ROT13은 교육용 고전 암호입니다.

자주 묻는 질문

AES-256-GCM이란?

현재 가장 안전한 대칭키 암호화 알고리즘 중 하나입니다. 256비트 키와 인증 태그(변조 탐지)를 사용하며, 이 도구는 비밀번호에서 PBKDF2로 키를 유도하고 매 암호화마다 새로운 salt·IV를 생성해 같은 평문·같은 비밀번호라도 매번 다른 암호문이 나오게 합니다.

내 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저에서만 이루어집니다. 외부로 데이터가 전송되지 않습니다.

Caesar cipher란?

알파벳을 N글자씩 이동시키는 고전 치환 암호입니다. 보안성이 낮아 교육용으로만 사용합니다.

ROT13이란?

Caesar cipher의 특수 케이스로 13글자씩 이동합니다. 같은 방법으로 복호화도 됩니다.

Vigenere cipher란?

키 단어를 반복하여 각 문자마다 다른 이동 값을 적용하는 다중 치환 암호입니다.

이동 수(shift)를 1~25 범위 밖으로 입력해도 정상 동작하나요?

네, 26으로 나눈 나머지를 항상 0 이상으로 보정하는 방식(((x%26)+26)%26)으로 계산하므로 0, 음수, 26 이상의 큰 값을 넣어도 암호화·복호화가 항상 정확히 원문으로 되돌아갑니다.

AES 암호화 결과를 복호화하려면?

이 페이지 상단의 '복호화' 탭으로 전환하여, 암호화할 때 사용한 것과 동일한 비밀번호와 AES-256-GCM 방식을 선택하면 복호화됩니다.

비밀번호를 잃어버리면?

AES 암호화의 경우 비밀번호 없이는 복호화가 불가능합니다. 또한 PBKDF2 반복 횟수(10만 회)는 암호문 자체에 저장되지 않고 도구 코드에 고정되어 있으므로, 이 페이지의 암호문은 반드시 같은 도구로 복호화해야 합니다.
