JSON to CSV 변환기란?

JSON 배열 데이터를 CSV(쉼표 구분 값) 형식으로 변환합니다. 객체마다 필드가 달라도 모든 객체의 키를 합쳐 헤더 열을 만들고, 특정 객체에 없는 키는 빈 셀로 채웁니다. 중첩 객체는 점 표기법(user.name)으로 평탄화되고, 배열 값은 JSON 문자열로 직렬화됩니다. 쉼표·세미콜론·탭·파이프 구분자를 지원하며, 값에 쉼표·줄바꿈·큰따옴표가 있으면 RFC 4180 규칙대로 자동으로 따옴표 처리됩니다. 다운로드하는 CSV 파일에는 UTF-8 BOM이 자동 포함되어 있어 Excel에서 바로 열어도 한글이 깨지지 않습니다.

자주 묻는 질문 (FAQ)

중첩된(nested) JSON 객체는 어떻게 처리되나요?

중첩 객체는 점 표기법(dot notation)으로 평탄화(flatten)됩니다. 예: {"user": {"name": "Kim"}} → user.name 열로 표시됩니다.

JSON 배열이 아닌 단일 객체도 변환할 수 있나요?

이 변환기는 객체 배열([{...}, {...}])에 최적화되어 있습니다. 단일 객체는 1행의 CSV로 변환됩니다.

값에 쉼표나 줄바꿈이 있으면 어떻게 처리되나요?

RFC 4180에 따라 해당 값은 자동으로 큰따옴표로 감싸집니다. Excel·Google Sheets에서 올바르게 파싱됩니다.

구분자는 어떻게 선택하나요?

유럽 국가에서는 쉼표 대신 세미콜론을 구분자로 사용하는 경우가 많습니다. 탭 구분자는 TSV(탭 구분 파일) 형식에 해당합니다.

대용량 JSON도 처리할 수 있나요?

브라우저에서 직접 처리하므로 서버 업로드 없이 사용 가능하지만, 매우 큰 파일(수만 행 이상)은 브라우저 성능에 영향을 줄 수 있습니다.

배열 안에 배열(중첩 배열)이 있으면 어떻게 되나요?

중첩 배열은 JSON.stringify()로 직렬화된 문자열로 표현됩니다. CSV는 2차원 구조이므로 완전한 중첩 배열을 별도 열로 분리하기는 어렵습니다.

null 또는 undefined 값은 CSV에서 어떻게 처리되나요?

null과 undefined는 빈 문자열("")로 변환됩니다. 스프레드시트에서 빈 셀로 표시됩니다.

CSV를 Excel에서 열면 한글이 깨지는데 어떻게 하나요?

다운로드 버튼으로 저장한 CSV 파일에는 UTF-8 BOM이 자동으로 포함되어 있어, 파일을 더블클릭해 바로 열어도 Excel이 UTF-8로 인식해 한글이 깨지지 않습니다. 별도의 "데이터 가져오기" 절차가 필요 없습니다.
