텍스트 케이스 감지기란?

프로그래밍에서 사용하는 camelCase, snake_case, PascalCase, kebab-case, UPPER_SNAKE 등 다양한 케이스 형식을 자동으로 감지하고 다른 형식으로 즉시 변환합니다. 변수명, 함수명, 파일명 변환에 유용합니다.

자주 묻는 질문

camelCase와 PascalCase 차이는?

camelCase는 첫 단어 소문자(myVar), PascalCase는 모든 단어 대문자 시작(MyVar)입니다.

snake_case는 어디서 쓰나요?

Python 변수명, 데이터베이스 컬럼명, Linux 파일명에 주로 사용합니다.

kebab-case는 어디서 쓰나요?

CSS 클래스명, URL 슬러그, HTML 속성명에 사용합니다.

UPPER_SNAKE_CASE는 어디서 쓰나요?

환경변수명, 상수 정의에 사용합니다(예: MAX_RETRY_COUNT).

PascalCase는 어디서 쓰나요?

JavaScript/TypeScript 클래스명, React 컴포넌트명, C# 클래스명에 사용합니다.

dot.case는 어디서 쓰나요?

설정 파일 키(config.database.host), 네임스페이스에 사용합니다.

숫자·약어가 섞이면 케이스가 어떻게 판별되나요?

판별 규칙: 단어 경계는 소문자→대문자 전환, 언더스코어, 하이픈 기준으로 나눕니다. 다만 이 도구의 판별 정규식은 연속된 대문자(약어) 뒤에 숫자나 또 다른 대문자가 오는 패턴은 인식하지 못합니다 — 예를 들어 "HTML5Parser"나 "userID2Name"은 어떤 케이스 패턴과도 일치하지 않아 "알 수 없음"으로 표시됩니다. 약어 뒤에 숫자가 붙는 패턴(HTML5, UTF8 등)이 포함된 문자열은 변환 결과를 항상 직접 확인하세요.

각 케이스는 실제로 어떤 언어·환경에서 쓰이나요?

실무 관례 매트릭스: camelCase — JavaScript/TypeScript 변수·함수명. snake_case — Python 변수·함수명, SQL/DB 컬럼명. kebab-case — CSS 클래스명, URL 슬러그, HTML 속성. PascalCase — JS/TS·C# 클래스명, React/Vue 컴포넌트명. UPPER_SNAKE_CASE(CONSTANT_CASE) — 환경변수(.env), 상수 선언. 언어의 공식 스타일 가이드(PEP8, Airbnb JS Style Guide 등)가 이 관례를 규정합니다.
