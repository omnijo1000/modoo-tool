PDF 페이지 회전

PDF 페이지는 실제 내용과 별개로 /Rotate 속성이라는 회전 값(0°, 90°, 180°, 270°)을 페이지마다 따로 저장합니다. 이 도구는 페이지 내용을 다시 그리지 않고 pdf-lib로 이 회전 값만 바꾸기 때문에, 큰 파일도 빠르고 화질 손실 없이 방향을 수정할 수 있습니다. 스캐너가 페이지를 가로·세로로 뒤집어 스캔했거나, 여러 문서를 병합했더니 일부 페이지만 방향이 다른 경우에 특히 유용합니다. 전체 페이지를 한 번에 돌리거나, "1,3,5-8"처럼 쉼표와 하이픈으로 특정 페이지만 지정해 회전할 수 있습니다.

자주 묻는 질문

특정 페이지만 회전할 수 있나요?

네, '특정 페이지' 옵션을 선택한 뒤 1,3,5-8처럼 쉼표로 개별 페이지를, 하이픈으로 연속 구간을 지정하면 됩니다. 지정하지 않은 나머지 페이지는 그대로 유지됩니다.

파일이 서버로 전송되나요?

아니요. pdf-lib가 브라우저 메모리 안에서 회전 값만 변경해 다시 저장하므로 파일이 외부로 전송되지 않습니다.

PDF 내용이 변경되나요?

아니요. 이 도구는 페이지의 텍스트나 이미지를 다시 렌더링하지 않고 페이지 메타데이터의 회전 각도(/Rotate)만 바꿉니다. 따라서 내용, 화질, 글자 선택 가능 여부 등은 전혀 손상되지 않습니다.

270° 회전은 왼쪽 회전인가요?

네. PDF의 회전 값은 항상 시계 방향 기준으로 누적되므로, 시계 방향 270° 회전은 결과적으로 반시계 방향(왼쪽) 90° 회전과 동일한 화면을 만듭니다.

대용량 PDF도 처리할 수 있나요?

회전은 페이지를 다시 그리는 작업이 아니라 값만 바꾸는 가벼운 연산이라 수백 페이지 문서도 비교적 빠르게 처리됩니다. 다만 파일 전체가 브라우저 메모리에 로드되므로 수백MB급 초대용량 PDF는 기기 성능에 따라 느려질 수 있습니다.

암호화된 PDF도 회전할 수 있나요?

아니요. 열람 암호가 걸린 PDF는 pdf-lib가 파일을 열 수 없습니다. PDF 암호 해제 도구로 먼저 잠금을 풀어야 합니다.

회전 후 파일 품질이 달라지나요?

달라지지 않습니다. 이미지를 재인코딩하거나 텍스트를 래스터화하는 과정이 없고 단순히 표시 각도만 바뀌므로, 해상도·폰트·벡터 그래픽 품질이 원본과 완전히 동일하게 유지됩니다.

모바일에서도 사용할 수 있나요?

네, pdf-lib가 표준 브라우저 API만 사용하므로 최신 모바일 브라우저에서도 파일 선택부터 다운로드까지 정상적으로 동작합니다.
