사이트맵 추출기

XML 사이트맵을 붙여넣어 URL과 메타데이터를 추출합니다

옵션:
0 total 0 filtered 0 prio ≥ 0.8
XML 사이트맵을 입력하고 추출 버튼을 클릭하세요

사이트맵 추출기

XML 형식의 사이트맵 내용을 붙여넣으면 DOMParser로 파싱해 URL 목록과 lastmod, priority, changefreq 정보를 테이블로 추출합니다. querySelectorAll('url,sitemap')로 태그를 조회하기 때문에 일반 <urlset> 사이트맵의 <url> 항목과 사이트맵 인덱스(<sitemapindex>)의 <sitemap> 항목을 별도 모드 전환 없이 한 번에 처리합니다. 필터 기능으로 특정 경로의 URL만 확인할 수 있으며, CSV로 내보내기도 지원합니다. 결과 테이블에 표시되는 URL은 HTML 이스케이프를 거치고 http/https로 시작하는 값만 클릭 가능한 링크로 렌더링해, 사이트맵에 악의적인 값이 섞여 있어도 안전하게 표시됩니다.

자주 묻는 질문

사이트맵 파일은 어디서 찾을 수 있나요?

일반적으로 https://example.com/sitemap.xml 또는 robots.txt 파일의 Sitemap: 디렉티브에서 찾을 수 있습니다.

사이트맵 인덱스 파일도 지원하나요?

네. 이 도구는 <url>과 <sitemap> 태그를 함께 조회하므로, 여러 하위 사이트맵을 가리키는 사이트맵 인덱스 파일을 붙여넣으면 각 <sitemap><loc> 항목이 URL 목록에 그대로 추출됩니다.

URL이 1,000개 이상인 경우 어떻게 하나요?

Google은 사이트맵당 50,000 URL까지 지원하며, 이 도구는 브라우저 메모리가 허용하는 한 모두 처리할 수 있습니다.

priority는 어떤 의미인가요?

0.0~1.0 범위로 사이트 내 상대적 중요도를 나타내는 값입니다. 다만 Google은 2014년부터 이 값을 크롤링 우선순위 결정에 사용하지 않는다고 공식적으로 밝혔으며, 이 도구는 참고용으로만 파싱·표시합니다.

changefreq는 무엇인가요?

페이지 업데이트 빈도 힌트입니다. always, hourly, daily, weekly, monthly, yearly, never 값을 사용하며, priority와 마찬가지로 실제 크롤링 스케줄을 강제하지는 않습니다.

CSV로 내보내면 무엇을 포함하나요?

URL, lastmod, priority, changefreq 네 개 열을 포함하며, 값 안에 큰따옴표나 쉼표가 있어도 깨지지 않도록 RFC 4180 방식으로 각 값을 큰따옴표로 감싸고 내부 큰따옴표는 두 번("")으로 이스케이프해 내보냅니다. Excel에서 바로 열 수 있습니다.

결과 테이블의 URL 링크가 안전한가요?

네. URL 값은 HTML 특수문자를 이스케이프해 삽입하며, http:// 또는 https://로 시작하는 값만 클릭 가능한 링크(target="_blank" rel="noopener noreferrer")로 렌더링합니다. javascript: 같은 스킴이나 따옴표·꺾쇠괄호가 섞인 값이 사이트맵에 들어 있어도 실행되거나 레이아웃이 깨지지 않습니다.

hreflang 태그도 추출되나요?

현재는 loc, lastmod, priority, changefreq만 추출합니다. hreflang alternate 링크는 별도 도구를 사용하세요.
