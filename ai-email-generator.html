이메일 템플릿 생성기

이메일 본문은 실제로는 항상 "인사말 → 핵심 내용 → 마무리 인사 → 발신자" 4단 구조 그대로 고정돼 있고, 8가지 이메일 유형(미팅 요청/제안서/사과 등) 아이콘은 그중 기본 제목(subject) 문구만 바꿔줄 뿐 본문 내용이나 구조에는 아무 영향을 주지 않습니다. 인사말과 마무리 인사는 선택한 톤(공식적/전문적/친근한/긴급)에 따라 정해진 문장으로 바뀌지만, 실제 이메일의 핵심 내용은 전적으로 '핵심 내용/맥락' 칸에 직접 입력한 텍스트가 그대로 들어갑니다. 또한 폼에 있는 '언어' 드롭다운은 실제 생성 로직에서 값을 읽어오지 않아 이메일에 아무 영향을 주지 않으며, 이메일 언어는 페이지 우측 상단의 🌐 버튼으로 전환한 현재 화면 언어를 그대로 따릅니다.

자주 묻는 질문

이메일 유형(미팅 요청/제안서/사과 등)을 바꾸면 본문도 달라지나요?

아니요. 8가지 유형 아이콘은 기본 제목(subject) 문구만 바꿔줄 뿐이며, 본문은 유형과 무관하게 항상 동일한 "인사말 → 핵심 내용 → 마무리 인사 → 발신자" 구조로 생성됩니다. 실제로 사과 이메일다운 문장, 제안서다운 문장은 이 도구가 써주지 않으므로 핵심 내용 칸에 직접 작성해야 합니다.

폼에 있는 '언어' 드롭다운에서 English를 선택하면 영어 이메일이 나오나요?

아니요. 이 드롭다운의 선택값은 실제 이메일 생성 함수에서 전혀 읽지 않습니다. 이메일이 어떤 언어로 만들어지는지는 이 드롭다운이 아니라 페이지 우측 상단의 🌐 언어 전환 버튼으로 바뀌는 현재 화면 언어에 따라 결정됩니다.

톤(공식적/전문적/친근한/긴급)을 바꾸면 무엇이 달라지나요?

인사말과 마무리 인사 문구만 톤에 맞는 고정 문장으로 바뀝니다. 예를 들어 '긴급' 톤은 인사말 앞에 [긴급] 표시가 붙고 마무리에 "빠른 회신 부탁드립니다"가 추가되는 식이며, 본문 중간의 핵심 내용 자체는 톤에 따라 다시 쓰이지 않습니다.

발신자/수신자 이름을 비워두면 어떻게 표시되나요?

입력하지 않으면 [발신자], [수신자] 같은 대괄호 placeholder 텍스트가 대신 들어갑니다. 이 placeholder는 화면 언어를 영어·중국어·일본어로 바꿔도 항상 한국어 텍스트로 고정되어 있어, 다른 언어로 생성할 때는 반드시 발신자·수신자 이름을 직접 입력하는 것이 좋습니다.

핵심 내용 칸을 비워두고 생성하면 어떻게 되나요?

"[핵심 내용을 입력해 주세요]"라는 대괄호 안내 문구가 본문 자리에 그대로 들어갑니다. 이 문구 역시 화면 언어와 무관하게 한국어로 고정되어 있으므로, 실제로 쓸모 있는 이메일을 만들려면 핵심 내용을 반드시 직접 입력해야 합니다.

'전체 복사' 버튼으로 복사하면 어떤 형식으로 복사되나요?

"제목: [생성된 제목]" 줄 다음에 빈 줄을 두고 본문 전체가 이어지는 형식으로 복사됩니다. 이 "제목:" 레이블은 화면 언어를 영어로 바꿔도 항상 한국어로 고정되어 있어, 영어 이메일을 복사해도 맨 앞의 레이블만 한국어로 남는 점에 유의해야 합니다.

이메일 제목은 어떻게 정해지나요?

선택한 유형별로 미리 정해둔 고정 제목 문구가 그대로 사용됩니다. 같은 유형을 선택하면 핵심 내용이나 발신자를 바꿔도 제목 문구 자체는 항상 동일하므로, 구체적인 제목이 필요하다면 생성 후 직접 수정해야 합니다.

생성된 이메일을 그대로 보내도 될까요?

인사말과 마무리는 정해진 문장이고 본문은 사용자가 입력한 텍스트 그대로이므로, 발송 전에 받는 사람 이름이 placeholder로 남아있지 않은지, 핵심 내용이 실제 상황에 맞게 구체적으로 작성됐는지 다시 확인한 뒤 사용하는 것을 권장합니다.
