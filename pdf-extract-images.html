PDF 이미지 추출

이 도구는 PDF 각 페이지를 텍스트나 벡터가 아닌 통짜 이미지로 렌더링하는 방식으로 동작합니다. PDF.js가 페이지를 HTML5 Canvas에 그린 뒤 이미지 데이터를 뽑아내며, DPI 개념 대신 배율(scale)을 사용합니다. 1배율은 PDF 표준 해상도인 72 DPI, 2배율은 144 DPI, 3배율은 216 DPI에 해당합니다(PDF 좌표계는 1pt=1/72인치를 기준으로 하기 때문). 배율이 커질수록 이미지 한 변의 픽셀 수가 배율만큼 늘어나 파일 용량과 렌더링 시간도 그만큼 증가합니다. 문서를 프레젠테이션 슬라이드에 붙여넣거나, 블로그·SNS에 페이지를 그대로 캡처해 올리거나, PDF를 열 수 없는 환경에서 미리보기용 이미지가 필요할 때 활용됩니다.

자주 묻는 질문

각 페이지를 개별 이미지로 받을 수 있나요?

네, 변환이 끝나면 각 페이지 카드 하단에 다운로드 버튼이 생기고, 이를 클릭하면 해당 페이지만 PNG 파일로 저장됩니다. 여러 페이지를 한꺼번에 zip으로 묶어 받는 기능은 아직 없어 페이지별로 개별 저장해야 합니다.

파일이 서버로 전송되나요?

아니요. PDF.js가 브라우저 안의 Canvas API로 직접 페이지를 렌더링하고 이미지 데이터를 만들어내므로 파일이 외부로 전송되지 않습니다.

고해상도로 추출하려면?

해상도 배율을 3×로 설정하면 216 DPI 품질로 렌더링됩니다. 인쇄나 확대 편집이 필요한 경우 3×를 권장하지만, 페이지 크기가 큰 문서는 이미지 한 장이 수십MB에 달할 수 있습니다.

페이지가 많으면 느린가요?

네. 각 페이지를 Canvas에 그리고 PNG로 인코딩하는 과정을 순차적으로 반복하기 때문에, 페이지 수와 배율이 커질수록 전체 소요 시간이 비례해서 늘어납니다. 100페이지 이상의 문서를 3× 배율로 변환하면 수 분이 걸릴 수 있습니다.

PDF 내 이미지만 추출할 수 있나요?

아니요. 이 도구는 페이지 전체(텍스트+벡터 그래픽+내장 이미지)를 하나의 PNG로 렌더링하는 방식이라, PDF 안에 삽입된 사진이나 로고 같은 개별 이미지 객체만 따로 뽑아낼 수는 없습니다. 그런 용도라면 PDF 내부 이미지 스트림을 직접 파싱하는 별도 도구가 필요합니다.

출력 형식은 PNG만 지원하나요?

네, 현재는 무손실 압축 방식인 PNG만 지원합니다. JPG처럼 용량이 더 작은 손실 압축 포맷은 아직 지원하지 않습니다.

암호화된 PDF도 처리되나요?

아니요. 열람 암호가 걸린 PDF는 PDF.js가 파일을 열 수 없어 처리할 수 없습니다. 먼저 암호를 해제해야 합니다.

모바일에서도 사용 가능한가요?

가능합니다. 다만 모바일 기기는 데스크톱보다 Canvas 렌더링 성능과 메모리가 제한적이라, 페이지 수가 많거나 3× 배율처럼 고해상도로 설정하면 데스크톱보다 훨씬 느리거나 브라우저가 일시적으로 멈출 수 있습니다.
