강력한 비밀번호 완벽 가이드

강력한 비밀번호는 최소 12자 이상이어야 하며 대문자, 소문자, 숫자, 특수문자를 섞어야 합니다. 이 생성기는 문자 하나마다 crypto.getRandomValues()로 암호학적으로 안전한 32비트 난수를 뽑아, 현재 켜져 있는 문자 종류 중에서 하나를 고릅니다 — 옵션을 전부 켜면 대문자26+소문자26+숫자10+특수문자26=총 88종입니다. 처리는 전부 브라우저 안에서 끝나 서버로 전송되거나 기록되지 않습니다. 88종 문자셋으로 만든 16자리 비밀번호의 엔트로피는 log₂(88)×16 ≈ 103비트로, 현재 알려진 어떤 하드웨어로도 무차별 대입에 사실상 무한한 시간이 걸립니다. 16자 이상을 권장하며, 계정마다 다른 비밀번호를 쓰고 비밀번호 관리자(Bitwarden, 1Password 등)에 저장하는 것이 최선의 보안 관행입니다.

사용 예시

  • SNS 계정 — 길이 16자 + 대소문자+숫자+특수문자 → 생성 → 복사 후 비밀번호 관리자에 저장
  • 회사 시스템 임시 비밀번호 — 길이 20자 + 대문자+숫자 + 모호 문자 제외 → 대량 생성(Bulk) → CSV 내보내기
  • WiFi 비밀번호 설정 — 길이 24자 + 영숫자만 → 생성 → 라우터 설정에 입력
  • API 키 생성 — 길이 32자 + 영숫자 → UUID 생성기와 함께 사용
  • PIN 코드 — 숫자만 선택 + 길이 6~8자 → 생성

자주 묻는 질문

비밀번호는 얼마나 길어야 하나요?

일반 계정은 최소 12자, 이메일·금융처럼 중요한 계정은 16자 이상을 권장합니다. 이 도구의 전체 문자셋(대문자26+소문자26+숫자10+특수문자26=총 88종)을 모두 쓴 16자리 비밀번호는 현재 어떤 하드웨어로도 무차별 대입에 사실상 무한한 시간이 걸립니다.

온라인 생성기가 안전한가요? 서버에 저장되지 않나요?

이 도구는 crypto.getRandomValues()(Web Crypto API)를 호출해 비밀번호를 브라우저 안에서만 만듭니다. 코드 어디에도 서버로 보내는 네트워크 요청이 없어 DevTools의 Network 탭으로 직접 확인할 수 있고, 인터넷 연결을 끊어도 정상 동작합니다.

모호한 문자 제외(0OlI1) 옵션은 언제 쓰나요?

생성된 비밀번호를 화면으로 보고 손으로 옮겨 적어야 할 때 유용합니다. 0(숫자 영)과 O(알파벳 오), 1(숫자 일)과 l(소문자 엘)·I(대문자 아이)처럼 폰트에 따라 헷갈리는 문자를 제거해 오타를 줄여줍니다. 이 옵션은 문자셋을 만든 뒤 정규식으로 해당 문자만 골라 제거하는 방식이라, 적용하면 전체 조합 수(엔트로피)가 약간 줄어듭니다.

강도 표시줄과 실제 비밀번호 엔트로피는 어떻게 다른가요?

화면의 강도 표시줄은 길이 구간(8/12/16자 이상)과 대문자·소문자·숫자·특수문자 포함 여부를 각각 1점씩 더하는 단순 휴리스틱(0~7점)입니다. 실제 무작위성(엔트로피)은 log₂(문자셋 크기)×길이(비트)로 계산합니다. 특수문자까지 켜면 이 도구의 문자셋은 88종이라, 16자리 비밀번호의 실제 엔트로피는 log₂(88)×16 ≈ 103비트입니다(128비트 이상이면 매우 강함으로 봅니다). 짧아도 문자 종류가 다양하면 강도 표시줄 점수는 높게 나올 수 있지만, 엔트로피 관점에서는 길이를 늘리는 쪽이 항상 더 효과적입니다.

특수문자가 포함되지 않는 비밀번호가 필요할 때는?

특수문자 옵션 체크를 해제하고 대신 길이를 24자 이상으로 늘리세요. 영숫자만 써도(62종 문자셋) 24자리면 log₂(62)×24 ≈ 143비트로, 특수문자를 포함한 16자리(약 103비트)보다 오히려 더 강력합니다.

대량 비밀번호 생성(Bulk) 기능은 언제 쓰나요?

사용자 계정 초기화, 서버 환경변수·API 키 발급, 테스트 계정 생성처럼 여러 개가 한꺼번에 필요할 때 최대 100개까지 한 번에 생성하고 전체 복사할 수 있습니다. 위쪽에서 고른 길이·문자 종류 옵션이 각 항목 생성에 그대로 적용됩니다.

기억하기 쉬운 강력한 비밀번호를 만드는 방법은?

패스프레이즈 방식을 추천합니다. 서로 관련 없는 단어 4~5개를 조합하면(예: correct-horse-battery-staple) 기억하기 쉬우면서도 무작위 문자 조합 못지않은 엔트로피를 얻을 수 있습니다. 이 도구는 문자 기반 생성기라 단어 조합 자체는 지원하지 않지만, 생성한 비밀번호를 외워야 할 마스터 비밀번호 하나로 쓰고 나머지는 비밀번호 관리자에 맡기는 것도 좋은 절충안입니다.

생성된 비밀번호는 어떻게 안전하게 보관해야 하나요?

Bitwarden(무료·오픈소스), 1Password, KeePassXC 같은 전용 비밀번호 관리자에 암호화 저장하는 것이 가장 안전합니다. 브라우저 자동완성이나 메모장·스프레드시트 보관은 기기 분실이나 악성코드에 훨씬 취약합니다. 계정마다 다른 비밀번호를 쓰고, 예전에 재사용하던 비밀번호가 유출된 적 있는지는 haveibeenpwned.com에서 무료로 확인할 수 있습니다.
