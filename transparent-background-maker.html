투명 배경 만들기

이미지에서 단색 배경을 제거해 투명 PNG를 만듭니다. 방식은 색상 키(color key) 방식입니다 — 선택한 배경색과 각 픽셀의 색상 거리(RGB 유클리드 거리)를 계산해, 거리가 허용 범위(tolerance) 이내면 거리에 비례해 알파(투명도)를 낮춥니다. 미리보기는 화면에 맞춰 축소된 캔버스에서 실시간으로 계산하지만, 다운로드 시에는 원본 해상도로 별도 캔버스를 다시 그려 같은 색상 제거 연산을 적용하므로 결과 PNG는 미리보기 크기가 아닌 원본 해상도를 유지합니다. "경계 부드럽게" 슬라이더는 알파 채널에만 박스 블러(box blur)를 적용해 색상 경계의 계단 현상을 완화합니다.

자주 묻는 질문

어떤 배경에 가장 잘 작동하나요?

흰색, 검정, 파란색 등 단색(uniform color) 배경에 가장 효과적입니다. 복잡한 배경이나 피사체와 배경색이 비슷한 경우 정밀도가 낮아질 수 있습니다.

허용 범위(Tolerance)란?

선택한 색상과 RGB 유클리드 거리가 (허용 범위 × 2.2) 이내인 픽셀까지 투명하게 처리합니다. 0은 정확히 같은 색상만, 100은 대부분의 색상을 제거합니다. 이 범위 안에서는 거리에 비례해 알파값이 선형으로 줄어들어, 색상 경계가 한 번에 뚝 끊기지 않고 자연스럽게 흐려집니다.

경계 부드럽게(Edge Smooth) 슬라이더는 무엇을 하나요?

값을 올리면 결과 이미지의 알파 채널에 지정한 반경만큼 박스 블러를 적용합니다. 색상 임계값만으로는 톱니 모양으로 남는 픽셀 경계를 부드러운 그라데이션으로 바꿔줍니다. 값 0이면 블러가 적용되지 않습니다.

다운로드한 PNG가 미리보기보다 해상도가 낮게 나오나요?

아니요. 미리보기 캔버스는 화면 표시를 위해 최대 360px로 축소되어 있지만, "PNG 다운로드" 버튼을 누르면 원본 이미지 크기(naturalWidth × naturalHeight)로 새 캔버스를 만들어 같은 색상 제거·경계 부드럽게 연산을 다시 적용한 뒤 저장합니다. 즉 원본 해상도가 그대로 유지됩니다.

결과물이 PNG로 저장되는 이유는?

투명도를 지원하는 형식은 PNG, WebP, GIF 등이지만, 이 도구는 가장 범용적인 PNG로 저장합니다.

복잡한 배경도 제거할 수 있나요?

이 도구는 단색 배경 제거에 최적화되어 있습니다. 복잡한 배경은 AI 기반 배경 제거 서비스(remove.bg 등)를 사용하는 것이 좋습니다.

파일이 서버에 업로드되나요?

아니요. Canvas API를 사용하여 브라우저에서 직접 처리됩니다.

여러 색상의 배경을 제거할 수 있나요?

현재 단일 색상 배경만 지원합니다. 여러 색상은 결과 PNG를 다시 업로드해 다른 색상으로 한 번 더 처리하거나, 허용 범위를 높여 사용하세요.
