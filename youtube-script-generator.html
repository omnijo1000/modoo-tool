유튜브 스크립트 생성기

이 도구는 AI가 매번 새로운 대본을 써주는 것이 아니라, 선택한 톤(친근함/전문적/교육적/엔터테이닝/동기부여)마다 미리 정해둔 훅 문장 1개에 주제를 끼워 넣고, 입력한 핵심 내용을 소개·본론·아웃트로 문장 틀에 순서대로 배치하는 방식으로 동작합니다. 특히 본론 부분은 핵심 내용 각 줄마다 "[여기에 ~관련 상세 설명, 예시, 데이터를 추가하세요]"라는 문구가 그대로 들어간 뼈대 형태로 나오므로, 실제 설명 내용은 사용자가 직접 채워야 합니다. 영상 길이는 라벨로만 선택할 뿐 실제 생성되는 문장 길이에는 영향을 주지 않으며, 결과 하단의 단어 수·예상 시간은 실제로 생성된 텍스트를 기준으로 사후 계산된 값입니다.

자주 묻는 질문

영상 길이를 30분으로 바꾸면 스크립트도 그만큼 길어지나요?

아니요. 코드상으로 영상 길이별 목표 단어 수(예: 130WPM 기준 30분=3,900단어)를 계산은 하지만, 실제 훅·소개·본론·아웃트로 문장 생성 로직에는 이 값이 반영되지 않습니다. 스크립트 분량은 오직 '핵심 내용' 칸에 몇 줄을 입력했는지에 따라서만 늘어나거나 줄어듭니다.

훅(Hook) 문장은 매번 다르게 생성되나요?

아니요. 선택한 톤마다 미리 작성된 훅 문장 틀이 하나씩 정해져 있고, 그 틀 안의 [주제] 자리에 입력한 주제를 그대로 끼워 넣는 방식입니다. 같은 주제와 톤으로 다시 생성해도 항상 동일한 훅 문장이 나옵니다.

본론(Body) 부분은 실제 내용까지 다 써주나요?

아니요. 핵심 내용을 한 줄 입력할 때마다 "▶ N번째: [내용]"이라는 제목 아래 "[여기에 ~관련 상세 설명, 예시, 데이터를 추가하세요]"라는 안내 문구가 그대로 삽입됩니다. 즉 본론은 완성된 설명이 아니라 어떤 순서로 무엇을 말할지 잡아주는 뼈대이며, 실제 설명·예시·데이터는 사용자가 직접 채워 넣어야 합니다.

핵심 내용을 5줄 넘게 입력하면 어떻게 되나요?

본론(Body)에는 입력한 줄 전부가 순서대로 들어가지만, 소개(Intro)와 아웃트로(Outro)의 요약 문장에는 keyPts.slice(0,3) 처리로 앞의 3개만 인용됩니다. 4번째 이후 핵심 내용은 본론에는 등장하지만 소개·아웃트로 요약에는 나오지 않습니다.

CTA 문구를 비워두면 어떻게 되나요?

CTA 입력란이 비어 있으면 "구독과 좋아요, 알림 설정까지 부탁드립니다..."라는 언어별 고정 기본 문구로 자동 대체됩니다. 입력한 값이 있으면 그 값이 그대로 사용됩니다.

예상 읽기 시간은 어떻게 계산되나요?

실제로 생성된 훅·소개·본론·CTA·아웃트로 전체 텍스트의 단어 수를 세어 말하기 속도 130WPM(분당 단어 수)으로 나눈 값입니다. 이는 영상 길이 선택값이 아니라 실제 생성된 결과물 기준의 사후 계산치입니다.

생성된 스크립트를 그대로 읽어도 자연스러울까요?

훅·소개·아웃트로는 정해진 문장 틀에 단어만 끼워 넣은 것이고 본론은 빈 뼈대이므로, 그대로 읽기보다는 참고용 골격으로 삼아 본인의 말투와 실제 설명 내용으로 다시 써서 사용하는 것을 권장합니다.

B-roll(보조 영상) 표시는 어디에 추가하나요?

이 도구에는 B-roll 표시 기능이 없으므로, 생성된 결과를 복사한 뒤 편집 단계에서 [B-roll: 설명] 같은 메모를 직접 추가해야 합니다.
