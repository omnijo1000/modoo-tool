PDF 비밀번호 추가

PDF 표준은 두 가지 종류의 비밀번호를 별도로 정의합니다. 사용자 비밀번호(User Password)는 파일 자체를 열람하기 위한 열쇠이고, 소유자 비밀번호(Owner Password)는 인쇄·복사·편집·주석 등 세부 권한을 제어하는 열쇠입니다. 이 도구는 pdf-lib의 암호화 기능으로 PDF 표준 보안 핸들러에 정의된 AES-128 암호화를 적용해, 열람 자체를 막거나 열람은 허용하되 특정 동작만 제한하는 두 가지 시나리오를 모두 지원합니다. 계약서·급여명세서처럼 열람 자체를 통제해야 하는 문서, 배포는 하되 재편집·재배포는 막고 싶은 보고서 등에 활용됩니다.

자주 묻는 질문

사용자 비밀번호와 소유자 비밀번호의 차이는?

사용자 비밀번호는 PDF 뷰어가 파일을 여는 순간 요구하는 비밀번호로, 이것이 없으면 내용을 아예 볼 수 없습니다. 소유자 비밀번호는 파일을 여는 것과 무관하게 인쇄·복사·편집 등의 권한을 잠그는 역할을 하며, 대부분의 뷰어는 이 비밀번호 없이도 열람은 허용하되 제한된 동작을 시도하면 막습니다.

비밀번호 없이 권한만 제한할 수 있나요?

네, 사용자 비밀번호는 비워두고 소유자 비밀번호만 입력하면 누구나 파일을 열어 볼 수는 있지만, 아래 체크박스에서 해제한 인쇄·복사·편집 등의 동작은 PDF 뷰어가 차단합니다.

파일이 서버로 전송되나요?

아니요. pdf-lib가 브라우저 메모리 안에서 직접 암호화를 수행하고 결과 파일을 만들어내므로, 원본이나 설정한 비밀번호가 외부로 전송되지 않습니다.

어떤 암호화 방식을 사용하나요?

AES-128 비트 암호화를 사용합니다. 이는 Adobe Acrobat 및 대부분의 PDF 리더가 지원하는 PDF 표준 암호화 방식으로, 구형 PDF 1.4 시절의 RC4 40비트 암호화보다 훨씬 안전합니다.

설정한 비밀번호를 잊으면 어떻게 되나요?

AES 암호화는 설계상 무차별 대입 공격에 강하도록 만들어져 있어, 비밀번호를 잊으면 원본 제작자조차 공식적인 방법으로는 복구할 수 없습니다. 반드시 비밀번호 관리자 등 안전한 곳에 별도로 기록해 두세요.

비밀번호를 다시 제거하려면?

비밀번호를 알고 있다면 PDF 비밀번호 제거 도구에 원본 비밀번호를 입력해 암호화를 해제할 수 있습니다. 비밀번호를 모른다면 이 도구로는 제거할 수 없습니다.

모바일에서도 사용할 수 있나요?

네, pdf-lib의 암호화 연산은 표준 브라우저 API(Web Crypto 등)를 기반으로 동작하므로 최신 모바일 브라우저에서도 파일 선택부터 다운로드까지 정상적으로 처리됩니다.

PDF 내용이 변경되나요?

아니요. 암호화는 파일을 저장하는 방식(보안 핸들러)만 바꿀 뿐, 텍스트·이미지·레이아웃 등 실제 콘텐츠는 전혀 수정하지 않습니다.
