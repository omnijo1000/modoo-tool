시스템 프롬프트 생성기

이 도구는 입력한 역할·회사명·톤·언어·목적·제한사항을 "# 역할 / # 응답 스타일 / # 주요 역할 / # 제한 사항" 순서의 마크다운 헤더 구조로 조립하며, 그 뒤에 "정확한 정보 제공", "모르면 인정" 같은 4가지 일반 원칙을 고정 문구로 항상 덧붙입니다. 이 일반 원칙 섹션은 어떤 역할을 입력하든 무조건 붙기 때문에, 캐릭터 롤플레이처럼 매우 특수한 페르소나를 만들 때는 이 일반 원칙이 원하는 캐릭터 설정과 미묘하게 충돌할 수 있습니다. 응답 언어를 "사용자 언어와 동일"로 설정하는 것은 실제로 AI가 그렇게 답하도록 보장하는 것이 아니라, 그렇게 하라는 지시문 한 줄을 프롬프트에 써넣는 것일 뿐입니다.

자주 묻는 질문

프리셋 버튼을 누르면 이미 입력해둔 내용이 사라지나요?

네. 프리셋을 클릭하면 확인 절차 없이 역할·목적·제한사항 입력칸이 즉시 프리셋 값으로 덮어써집니다. 다만 회사명, 응답 스타일, 응답 언어 선택은 그대로 유지되고 프리셋의 영향을 받지 않습니다.

"일반 원칙" 섹션은 매번 똑같이 붙나요?

네. 역할·목적·제한사항을 무엇으로 입력하든 상관없이 "정확한 정보 제공", "모르는 내용 인정" 등 4개 항목이 결과 맨 끝에 고정으로 추가됩니다. 매우 특수한 캐릭터 페르소나를 만들 때는 이 고정 문구가 원하는 설정과 어색하게 겹칠 수 있어 직접 수정하거나 삭제해야 할 수 있습니다.

응답 언어를 "사용자 언어와 동일"로 설정하면 실제로 그렇게 동작함을 보장하나요?

아니요. 이 도구는 해당 옵션을 선택하면 "사용자의 언어로 응답하세요"라는 지시문 한 줄을 프롬프트 텍스트에 써넣을 뿐이며, 실제 AI 모델이 그 지시를 얼마나 잘 따르는지는 사용하는 모델과 상황에 따라 달라집니다.

생성된 프롬프트의 토큰 수를 이 페이지에서 확인할 수 있나요?

아니요. FAQ에서 안내하는 1,000~4,000토큰 권장 범위와 비교해보려면, 생성된 텍스트를 복사해 별도의 토큰 계산 도구(예: 이 사이트의 프롬프트 토큰 계산기)에 붙여넣어 직접 확인해야 합니다.

회사명 칸을 비워두면 어떻게 되나요?

"[회사명]를 위해 작동합니다."라는 문장 하나만 결과에서 빠지고 나머지 구조(역할, 응답 스타일, 목적, 제한사항, 일반 원칙)는 그대로 조립됩니다.

# 역할, # 응답 스타일 같은 마크다운 헤더 형식이 모든 AI 서비스의 표준인가요?

아니요. 이는 프롬프트를 섹션별로 읽기 쉽게 나누는 흔한 관례 중 하나일 뿐, 특정 플랫폼이 강제하는 공식 포맷은 아닙니다. 일부 서비스나 API는 자체적인 시스템 메시지 형식을 요구할 수 있으니 대상 플랫폼의 가이드를 함께 확인하는 것이 좋습니다.

응답 스타일(전문적/친근한 등) 선택은 정확히 무엇을 바꾸나요?

"# 응답 스타일" 섹션 문장 안의 형용사 표현 하나만 바뀝니다("전문적이고 명확한", "친근하고 따뜻한" 등). 역할이나 제한사항 등 나머지 섹션의 문구에는 영향을 주지 않습니다.

생성된 프롬프트를 그대로 사용해도 될까요?

구조는 갖춰져 있지만 "일반 원칙" 고정 문구가 항상 붙는다는 점과 응답 언어 지시가 실제 동작을 보장하지 않는다는 점을 감안해, 실제 사용하려는 모델에 붙여 넣고 몇 차례 테스트해본 뒤 필요한 부분을 다듬어 사용하는 것을 권장합니다.
