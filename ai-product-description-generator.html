제품 설명 템플릿 생성기

이 도구는 혜택 중심·기능 중심·스토리텔링·미니멀 4가지 스타일마다 문구를 이어 붙이는 순서가 다른 고정 틀을 가지고 있는데, 그 틀 안에 들어가는 연결 문구("~를 위한 최적의 선택입니다", "상세 사양", "차별점:", "당신의 일상을 바꿀" 등)는 화면 표시 언어와 무관하게 전부 한국어로 고정돼 있습니다. 그래서 영어·중국어·일본어 화면에서 생성해도 연결 문구는 한국어 그대로 나오고, 오직 사용자가 직접 입력한 제품명·기능·타겟·혜택 텍스트만 입력한 언어로 보입니다. 또한 폼에 있는 '카테고리' 드롭다운은 실제 생성 로직에서 값을 전혀 읽지 않는 장식용 항목이라, 어떤 카테고리를 선택해도 결과 문구에는 아무 영향이 없습니다.

자주 묻는 질문

카테고리 선택이 설명 내용에 실제로 반영되나요?

아니요. '카테고리' 드롭다운 값은 생성 함수(generate()) 어디에서도 읽어오지 않습니다. 전자제품을 선택하든 패션을 선택하든 결과 텍스트는 완전히 동일합니다.

영어·중국어·일본어 화면에서 생성해도 한국어가 섞여 나오나요?

네. 4가지 스타일 모두 문구를 이어 붙이는 연결어("를 위한 최적의 선택입니다", "상세 사양" 등)가 화면 언어와 무관하게 한국어로 고정돼 있습니다. 사용자가 입력한 제품명·기능·혜택 텍스트만 해당 언어로 나오고, 그 사이를 잇는 문구는 항상 한국어입니다.

'혜택 중심' 스타일은 정확히 어떤 순서로 조립되나요?

제품명 → (입력했다면) 핵심 혜택 문단 → "[타겟 고객]를 위한 최적의 선택입니다." → "📋 주요 기능" 아래 입력한 기능 전체를 글머리 기호로 나열하는 순서로 고정돼 있습니다.

'미니멀' 스타일은 다른 스타일과 어떻게 다른가요?

제품명과 핵심 기능 중 앞의 5개만 가운뎃점(·)으로 이어 한 줄로 보여줍니다. 핵심 혜택이나 타겟 고객 칸에 아무리 자세히 입력해도 이 스타일에서는 해당 내용이 전혀 사용되지 않습니다.

'기능 중심' 스타일에서 타겟 고객 입력은 쓰이나요?

아니요. 기능 중심 템플릿은 제품명·핵심 기능 목록·"차별점: [핵심 혜택]"만 조립할 뿐 타겟 고객 값은 아예 참조하지 않으므로, 이 칸을 채워도 기능 중심 스타일 결과에는 나타나지 않습니다.

핵심 기능은 몇 개까지 반영되나요?

혜택 중심·기능 중심·스토리텔링 스타일은 입력한 기능을 쉼표 기준으로 나눠 개수 제한 없이 전부 나열합니다. 반면 미니멀 스타일만 앞의 5개(slice(0,5))로 제한합니다.

입력 칸을 비워두면 어떻게 표시되나요?

비워둔 칸은 대괄호 placeholder 없이 해당 문장이나 섹션 자체가 통째로 생략됩니다. 예를 들어 핵심 혜택을 비워두면 혜택 문단 없이 나머지 부분만 조립됩니다(제품명만은 비워두면 '제품'이라는 기본값으로 대체됩니다).

생성된 설명을 그대로 사용해도 될까요?

사용자가 입력한 내용은 그대로 반영되지만 연결 문구는 항상 한국어로 고정돼 있으므로, 비한국어로 제품 설명을 만들었다면 문장 사이 연결어를 직접 해당 언어로 바꿔 쓰는 과정이 반드시 필요합니다.
