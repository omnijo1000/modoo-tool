이미지 프롬프트 생성기

Midjourney, DALL-E, Stable Diffusion에 맞는 형식으로 프롬프트를 생성합니다. Midjourney와 Stable Diffusion 모드는 선택한 요소들을 쉼표로 이어붙이는 방식이라 깔끔하지만, DALL-E 모드는 분위기·스타일·주제 값을 하나의 문장 템플릿에 끼워 넣는 방식이라 분위기·스타일을 선택하지 않으면 "A a cat"처럼 불필요한 공백이 여러 개 겹쳐 들어가고, 선택했을 때도 "A dramatic photorealistic image of a cat"처럼 단어 사이에 공백이 두 번씩 들어갑니다. 또한 네거티브 프롬프트 입력창은 DALL-E 모드에서도 그대로 표시되고 입력도 되지만, 실제 생성 코드에는 반영되지 않아 입력한 내용이 결과에 전혀 나타나지 않습니다.

자주 묻는 질문

DALL-E 모드에서 프롬프트에 공백이 이상하게 여러 개 들어가는 게 사실인가요?

네, 재현됩니다. 스타일과 분위기를 아무것도 선택하지 않고 주제만 "a cat"으로 입력하면 결과는 "A a cat"처럼 "A"와 "a cat" 사이에 공백이 3개 들어갑니다. 스타일·분위기를 선택해도 "A dramatic photorealistic image of a cat"처럼 단어 사이에 공백이 두 번씩 겹칩니다.

왜 이런 공백 문제가 생기나요?

DALL-E용 프롬프트를 만드는 템플릿 리터럴 자체에 mood+' '처럼 값 뒤에 이미 공백을 붙여두고, 그 뒤에 템플릿의 고정 공백까지 또 들어가는 구조라 공백이 중복됩니다. 값이 비어 있을 때도 삼항연산자가 빈 문자열만 반환할 뿐 그 뒤 고정 공백은 그대로 남기 때문에 값이 없어도 자리 공백이 남습니다.

네거티브 프롬프트를 입력했는데 DALL-E 결과에 왜 안 보이나요?

코드상 네거티브 프롬프트 처리는 Midjourney 모드(--no 파라미터로 추가)와 Stable Diffusion 모드(별도 줄로 추가)에만 있고, DALL-E 분기 코드에는 negative 값을 사용하는 부분이 아예 없습니다. 입력창은 모델과 무관하게 항상 보이고 입력도 되지만, DALL-E를 선택한 상태로 생성하면 입력한 내용이 조용히 버려집니다.

이건 버그인가요, 아니면 DALL-E가 원래 네거티브 프롬프트를 지원 안 하는 건가요?

DALL-E API 자체가 Midjourney의 --no나 Stable Diffusion의 negative prompt 같은 개념을 공식 지원하지 않는 것은 사실입니다. 문제는 그 사실과 무관하게, 이 도구가 DALL-E 모드에서도 네거티브 프롬프트 입력창을 계속 활성화된 채로 보여준다는 점입니다. 사용자는 입력한 내용이 반영되는지 아닌지 알 방법이 없습니다.

Midjourney와 Stable Diffusion 모드에도 같은 공백 문제가 있나요?

아니요. 두 모드는 선택된 요소들을 배열에 담아 parts.join(', ')로 쉼표+공백 하나씩만 넣어 이어붙이는 방식이라 이런 중복 공백 문제가 없습니다. 문제는 DALL-E 분기의 템플릿 리터럴 조립 방식에서만 발생합니다.

품질 태그는 무엇인가요?

masterpiece, best quality, ultra detailed 등 이미지 품질을 높이는 것으로 알려진 키워드로, 선택하면 프롬프트 끝에 추가됩니다.

Midjourney --ar, --v, --q 파라미터는 무엇을 의미하나요?

--ar는 종횡비(예: 16:9), --v는 모델 버전, --q는 렌더링 품질 단계를 지정합니다. 이 도구는 Midjourney 모드에서 --ar 16:9 --v 6.1 --q 2를 기본값으로 항상 붙입니다.

한국어로 주제를 입력해도 되나요?

입력 자체는 가능하지만, 대부분의 AI 이미지 생성 모델은 영어 프롬프트에서 더 안정적인 결과를 냅니다. 가능하면 주제와 세부 묘사를 영어로 입력하는 것을 권장합니다.
