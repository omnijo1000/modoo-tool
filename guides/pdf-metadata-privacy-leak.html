이력서에 몰래 딸려가는 정보 — PDF 메타데이터 유출 완전정리

가이드 · 2026-08-19 최종 확인

PDF 파일을 열어 눈에 보이는 텍스트와 이미지만 지우면 안전하다고 생각하기 쉽지만, PDF는 화면에 표시되지 않는 정보를 파일 내부에 별도로 저장합니다. 이력서를 작성한 컴퓨터의 사용자 계정명, 예전에 지원했던 회사명이 남은 문서 제목, 사내 워드·한글 프로그램의 버전 정보 같은 것들이 여기에 해당합니다. 문제는 이 메타데이터가 한 군데가 아니라 두 군데에 이중으로 저장된다는 점이며, 이 구조를 모르고 한쪽만 지운 채 "익명화 완료"라고 착각하는 경우가 실제로 발생합니다.

1. Info Dictionary와 XMP — 왜 저장소가 두 개인가

PDF 표준이 처음 만들어졌을 때(어도비의 초기 PDF 1.0 명세)부터 존재한 메타데이터 저장 방식은 Info Dictionary입니다. 파일 끝부분의 트레일러 영역에 Title, Author, Subject, Keywords, Creator, Producer, CreationDate, ModDate 같은 키와 값을 단순한 쌍으로 나열하는 구조로, 가볍고 파싱하기 쉽지만 표현할 수 있는 정보의 폭이 좁습니다. 이후 어도비는 포토샵·인디자인·일러스트레이터 등 다른 제품군과 파일 형식을 넘나들며 메타데이터를 공유하고, 저작권 정보나 편집 이력처럼 더 복잡한 구조를 담기 위해 XMP(Extensible Metadata Platform)라는 XML 기반 메타데이터 체계를 새로 도입했습니다. 문제는 XMP를 도입하면서 기존 Info Dictionary를 없애지 않고 그대로 남겨둔 채 병행하는 방식을 택했다는 점입니다. 하위 호환성을 지키기 위한 선택이었지만, 그 결과 현재의 PDF는 사실상 같은 정보를 두 벌로 들고 다니는 구조가 됐습니다.

2. 두 저장소가 서로 동기화되지 않는 이유

Info Dictionary와 XMP는 서로 다른 시점에, 서로 다른 소프트웨어에 의해 독립적으로 기록되고 수정됩니다. 문서를 처음 만든 워드프로세서는 두 저장소 모두에 초기값을 채워 넣지만, 이후 그 파일을 다른 도구로 편집하거나 "속성" 창에서 제목·작성자만 수동으로 바꾸면 대부분의 프로그램은 Info Dictionary만 갱신하고 XMP는 손대지 않습니다. 반대의 경우도 마찬가지로, 일부 온라인 PDF 편집 도구나 익명화 스크립트는 XMP 블록만 깨끗이 비우고 예전 방식인 Info Dictionary는 아예 건드리지 않기도 합니다. 두 저장소를 하나로 묶어 자동으로 맞춰주는 표준 규칙이 없기 때문에, "메타데이터를 지웠다"는 말이 실제로는 절반만 지운 상태를 의미하는 경우가 흔합니다. 그래서 회사명·작성자명을 Author 필드에서 지웠다고 안심했는데, 같은 정보가 XMP 안에 그대로 남아 있어 파일 속성을 조금만 깊이 들여다보면 원본 정보가 고스란히 드러나는 사고가 발생합니다.

실제로 보고되는 유출 유형: 이력서 PDF의 제목(Title)이나 주제(Subject) 필드에 이전에 지원했던 회사명이나 사내 프로젝트명이 그대로 남아 다른 회사에 그대로 제출되는 경우, 워드의 "변경 내용 추적" 작성자 정보가 문서 내부나 Author 필드에 남아 실제 작성자(대필 여부 포함)가 드러나는 경우, 회사 공용 템플릿을 재사용하면서 Producer·Creator 필드에 사내 시스템명이나 사번이 포함된 사용자 계정명이 노출되는 경우가 대표적입니다.

3. 제출 전 확인 순서

공문서나 이력서를 외부에 보내기 전에는 눈에 보이는 본문만이 아니라 파일 내부 메타데이터까지 확인하는 습관이 필요합니다. 먼저 PDF 메타데이터 뷰어로 제목·저자·작성 프로그램·변환 프로그램 값에 의도치 않은 정보가 없는지 살펴보고, 문제가 있다면 PDF 메타데이터 제거 도구로 정리합니다. 이때 중요한 점은 제거 도구가 Info Dictionary와 XMP를 모두 함께 지우는지 확인하는 것입니다. 한쪽만 지우는 도구를 쓰면 지웠다고 믿었던 정보가 다른 한쪽에 그대로 남아있을 수 있기 때문에, 정리 후에는 다시 메타데이터 뷰어로 두 저장소 모두 비어있는지 재확인하는 절차를 거치는 것이 안전합니다.

4. 정리

  • PDF는 메타데이터를 이중 저장: 오래된 Info Dictionary와 Adobe가 나중에 추가한 XMP가 병행 존재합니다.
  • 한쪽만 지우면 불완전: 두 저장소는 자동으로 동기화되지 않으므로 하나만 지워서는 완전 삭제가 아닙니다.
  • 제출 전 이중 확인: 메타데이터 뷰어로 확인 → 제거 도구로 정리 → 다시 뷰어로 재확인하는 순서를 권장합니다.

자주 묻는 질문

Q. PDF 메타데이터는 파일 안 어디에 저장되나요?

A. 두 곳입니다. 하나는 PDF 트레일러에 있는 Info Dictionary(제목·저자 등 단순 키-값 쌍), 다른 하나는 Adobe가 도입한 XMP(XML 기반 메타데이터)입니다. 최신 PDF는 대부분 두 곳 모두에 메타데이터를 기록합니다.

Q. 왜 두 가지 저장 방식이 따로 존재하나요?

A. Info Dictionary는 PDF 1.0부터 있던 원래 방식으로 단순하지만 표현할 수 있는 정보가 제한적입니다. Adobe는 이후 다른 어도비 제품군(포토샵, 인디자인 등)과 메타데이터를 공유하고 저작권·편집 이력 같은 복잡한 정보까지 표현하기 위해 XML 기반의 XMP를 별도로 추가했습니다. 하위 호환을 위해 기존 Info Dictionary를 없애지 않고 병행하는 구조가 굳어졌습니다.

Q. 저자 이름을 지웠는데 왜 여전히 정보가 남아있나요?

A. 많은 문서 편집 프로그램이나 온라인 도구가 Info Dictionary만 수정하고 XMP는 그대로 두거나, 반대로 XMP만 정리하고 Info Dictionary는 건드리지 않기 때문입니다. 두 저장소가 서로 자동 동기화되지 않으므로 한쪽만 지우면 다른 쪽에 원본 정보가 그대로 남을 수 있습니다.

Q. 이력서·계약서를 제출하기 전에 무엇을 확인해야 하나요?

A. PDF 메타데이터 뷰어로 제목·저자·작성 프로그램·변환 프로그램 필드에 이전 회사명, 실제 작성자명, 사내 시스템 이름 같은 정보가 남아있지 않은지 확인하고, 필요하면 메타데이터 제거 도구로 Info Dictionary와 XMP를 함께 정리한 뒤 제출하는 것이 안전합니다.
