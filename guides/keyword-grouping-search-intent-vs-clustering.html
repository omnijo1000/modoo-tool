검색 의도 분류와 키워드 클러스터링은 다른 개념이다

가이드 · 2026.08.26 최종 확인

"키워드 그룹화(grouping)"라는 이름 때문에 키워드 그룹화 툴을 쓰면 의미가 비슷한 키워드끼리 자동으로 묶여서 콘텐츠 클러스터 기획까지 끝날 것으로 기대하는 경우가 많습니다. 하지만 실제 코드를 열어보면 이 도구가 하는 일은 완전히 다른 작업입니다. 이름은 비슷해도 기법이 다른 두 SEO 개념을 정확히 구분해 보겠습니다.

1. 이름이 비슷해서 자주 섞이는 두 기법

SEO 실무에서 "키워드를 묶는다"는 말은 최소 두 가지 완전히 다른 작업을 가리킬 수 있습니다.

기법목적대표 방식
검색 의도 분류(Search Intent Classification)키워드 하나하나가 "왜" 검색됐는지 목적을 4가지 범주로 태깅키워드에 특정 단어("방법","이란","구매","가격" 등)가 포함됐는지 사전과 대조하는 규칙 기반 매칭
키워드 클러스터링(Keyword Clustering)의미가 비슷한 키워드 여러 개를 하나의 콘텐츠 페이지로 묶기임베딩 벡터 간 거리, 또는 실제 구글 SERP 결과의 중복도(같은 페이지가 여러 키워드에서 동시에 상위 노출되는지) 계산

전자는 키워드 "개별"의 목적을 분류하는 일이고, 후자는 키워드 "여러 개 사이"의 관계를 계산하는 일입니다. 완전히 다른 입력·출력 구조를 가진 별개의 기법입니다.

2. 이 도구가 실제로 하는 일: 사전 매칭 기반 의도 분류

키워드 그룹화 툴의 실제 로직을 코드로 확인한 결과, classifyKeyword() 함수는 각 키워드를 소문자로 바꾼 뒤 informational·commercial·transactional·navigational 4개 카테고리에 미리 등록된 한국어·영어 단어 목록과 부분 문자열 포함 여부(includes)를 하나씩 대조합니다. 예를 들어 "방법", "이란", "가이드" 등의 단어가 포함되면 informational로, "구매", "가격", "할인" 등이 포함되면 transactional로 분류됩니다. 임베딩 모델도, 벡터 유사도 계산도, 외부 API 호출도 전혀 없는 순수한 정적 사전 매칭입니다.

실제 판정 예시 (INTENT 딕셔너리 기준):
입력 키워드매칭된 단어분류 결과
SEO 최적화 방법"방법" 포함informational
SEO 도구 추천"추천" 포함commercial
SEO 도구 구매"구매" 포함transactional
모두의 툴 로그인"로그인" 포함navigational
백링크 구축 전략사전에 없는 단어 조합unknown (미분류)

3. 여러 카테고리 단어가 동시에 들어 있으면 어떻게 되나

코드를 보면 카테고리는 informational → commercial → transactional → navigational 순서로 검사하고, 가장 먼저 매치되는 카테고리에서 즉시 멈춥니다. 즉 한 키워드에 두 카테고리 단어가 동시에 들어 있어도 나중 카테고리로는 절대 분류되지 않습니다. 예를 들어 "SEO 도구 추천 가격 비교"처럼 커머셜 단어("추천")와 트랜잭셔널 단어("가격")가 함께 있으면, informational 사전에 걸리는 단어가 없다고 가정할 때 먼저 검사되는 commercial로 확정되고 transactional 여부는 아예 검사조차 되지 않습니다. 이건 진짜 클러스터링에는 없는, 사전 매칭 특유의 "선착순" 구조입니다.

4. 진짜 키워드 클러스터링이 하는 일

반면 진짜 클러스터링은 키워드 하나의 목적을 판정하는 게 아니라, 키워드 집합 안에서 "이 여러 개를 한 페이지에 담아도 되는가"를 계산합니다. 대표적으로 두 방식이 쓰입니다. 첫째는 각 키워드를 임베딩 벡터로 변환해 코사인 유사도가 일정 임계값 이상이면 같은 클러스터로 묶는 방식이고, 둘째는 각 키워드를 실제 구글에 검색했을 때 상위 10위 결과 URL이 서로 얼마나 겹치는지(SERP overlap)를 계산해 겹침이 크면 구글이 이미 두 키워드를 "같은 주제"로 취급한다고 보고 묶는 방식입니다. 두 방식 모두 외부 데이터(임베딩 모델 또는 실시간 SERP)가 필요하며, 이 사이트의 키워드 그룹화 툴과 키워드 클러스터링 툴은 별개의 도구로 존재합니다.

5. 실무에서 어떻게 함께 쓰면 좋은가

두 기법은 경쟁 관계가 아니라 순서가 다른 별개 단계입니다. 먼저 검색 의도 분류로 원시 키워드 목록을 4가지 목적별로 크게 나눠 콘텐츠 형식(가이드형/비교형/랜딩페이지형/브랜드형)을 결정하고, 그다음 같은 의도 그룹 안에서 클러스터링으로 세부 주제를 다시 묶어 필러-클러스터 콘텐츠 구조를 설계하는 순서가 일반적입니다. 의도 분류만 하고 클러스터링을 생략하면 같은 주제를 다루는 페이지가 여러 개로 쪼개져 키워드 밀도 검사기로 개별 페이지를 아무리 최적화해도 사이트 전체의 토픽 권위도는 오르지 않습니다.

자주 묻는 질문

Q. 키워드 그룹화 툴은 AI나 임베딩을 사용하나요?

A. 아니요. 실제 코드는 소문자 변환 후 미리 등록된 한국어·영어 단어 목록과 부분 문자열 포함 여부를 대조하는 정적 사전 매칭만 수행합니다. 임베딩·API 호출은 전혀 없습니다.

Q. 한 키워드가 여러 의도 단어를 동시에 포함하면 어떻게 되나요?

A. informational → commercial → transactional → navigational 순서로 검사해 가장 먼저 매치되는 카테고리 하나로만 확정됩니다. 이후 카테고리는 검사되지 않습니다.

Q. 사전에 없는 단어로만 이뤄진 키워드는 어떻게 분류되나요?

A. 4가지 사전 어디에도 걸리지 않으면 "unknown(미분류)"으로 분류됩니다. 사전을 벗어난 표현이나 신조어는 분류되지 않을 수 있습니다.

Q. 진짜 키워드 클러스터링은 이 사이트에서 어디서 하나요?

A. 검색 의도 분류는 키워드 그룹화 툴, 의미 기반 클러스터링은 별도의 키워드 클러스터링 툴이 담당합니다. 이름이 비슷해 보여도 서로 다른 도구입니다.

Q. 사전 매칭 방식의 한계는 무엇인가요?

A. 등록된 단어를 문자 그대로 포함하는지만 보므로 동의어·문맥·어순을 이해하지 못합니다. 예를 들어 사전에 없는 신조어나 은어는 무조건 미분류로 빠집니다.
