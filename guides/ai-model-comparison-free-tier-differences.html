GPT vs Claude vs Gemini, 무료 티어는 뭐가 다른가

가이드 · 2026.08.20 최종 확인

"AI를 무료로 쓸 수 있나요?"라는 질문에 한 문장으로 답하기 어려운 이유는, 회사마다는 물론이고 같은 회사, 같은 모델 계열 안에서도 무료 여부가 갈리기 때문입니다. 이 가이드는 AI 모델 비교표에 실제로 등록된 12개 모델 데이터를 근거로, 왜 무료 티어가 회사별·모델별로 이렇게 들쭉날쭉한지 구조적으로 설명합니다.

1. 무료 티어는 "회사 정책"이 아니라 "모델별 정책"

가장 흔한 오해가 "OpenAI는 유료, Google은 무료"처럼 회사 단위로 무료 여부를 나누는 것입니다. 실제로는 그렇지 않습니다. AI 모델 비교표의 소스 코드를 열어 보면 OpenAI 계열 5개 모델(GPT-4o, GPT-4o mini, GPT-4 Turbo, o1, o3-mini)과 Anthropic 계열 3개 모델(Claude Opus, Sonnet, Haiku)은 전부 free:false로 유료 전용 처리되어 있는 반면, Google 계열 4개 모델 중에서는 free:true와 free:false가 한 회사 안에서 섞여 있습니다. 즉 "무료냐 아니냐"는 제공사 단위가 아니라 개별 모델 단위로 결정되는 정책입니다.

2. 같은 Gemini인데 왜 한 모델만 유료인가

비교표에 등록된 Google Gemini 4개 모델 중 1.5 Pro·1.5 Flash·2.0 Flash 3개는 무료 API 티어가 있지만, 나머지 하나인 Gemini 2.0 Pro는 무료 티어 없이 유료로만 제공되는 것으로 표기되어 있습니다. 같은 "2.0" 세대, 같은 Google 브랜드인데도 Pro 등급만 무료 티어에서 빠지는 이유는 무료 티어가 대체로 "가벼운 실험·프로토타이핑용"으로 설계되기 때문입니다. Flash 계열은 속도·비용이 낮아 무료로 열어도 서버 부담이 적지만, 2M 토큰 컨텍스트를 지원하는 최상위 Pro 모델은 요청 1건의 연산 비용 자체가 커서 무료로 풀기 어렵습니다. "같은 브랜드=같은 조건"이라는 직관이 여기서 깨지는 셈입니다.

3. 왜 OpenAI·Anthropic 라인업은 통째로 유료인가

비교표 기준으로 OpenAI·Anthropic 모델 8개는 예외 없이 free:false입니다. 두 회사는 대신 API가 아닌 채팅 웹앱(ChatGPT, Claude.ai)에서 무료 사용량을 제공하는 방식을 택하고 있습니다. 즉 "API로 무료 호출"과 "웹 채팅으로 무료 대화"는 완전히 다른 트랙이라는 점이 중요합니다. 이 도구의 비교표는 API 가격만 다루므로, 웹 채팅에서 느끼는 "나는 무료로 잘 쓰고 있는데?"라는 경험과 표에 찍힌 유료 표시가 모순처럼 보일 수 있습니다. 개발자가 자기 서비스에 API로 붙이려는 경우와, 일반 사용자가 채팅창에서 질문하는 경우는 무료 여부를 완전히 다른 기준으로 따져야 합니다.

4. 무료 티어의 숨은 비용: 요청 한도

무료 티어가 있다고 해서 "제한 없이 공짜"라는 뜻은 아닙니다. Gemini 계열 무료 티어는 분당 요청 수(RPM), 일일 요청 수(RPD) 같은 상한이 걸려 있는 것이 일반적이며, 이 상한을 넘기면 요청이 거부되거나 자동으로 유료 결제로 전환됩니다. 비교표의 비고(note) 컬럼에 Gemini 1.5 Flash가 "Ultra-fast", 2.0 Flash가 "Next-gen fast"로 표시된 것도 이 두 모델이 가벼운 연산 비용 덕에 무료 티어의 요청 한도 안에서도 실용적으로 쓸 수 있다는 맥락과 맞닿아 있습니다. 반면 1.5 Pro는 무료 티어가 있어도 한도가 더 낮게 걸리는 경우가 많아, 실서비스보다는 테스트 용도로 적합합니다.

5. 이 데이터를 확인할 때 주의할 점

AI 모델 비교표는 페이지 하단에 스스로 "AI 가격은 자주 바뀌므로 최신 수치는 각 공급사 공식 페이지에서 재확인하는 것이 안전합니다"라고 명시하고 있습니다. 실제로 무료 티어 정책과 요청 한도는 각 회사가 예고 없이 조정하는 항목이라, 이 표에 찍힌 12개 모델 라인업과 가격도 스냅샷일 뿐입니다. 이 가이드에서 다룬 "같은 Gemini인데 Pro만 유료"라는 구조적 패턴 자체는 참고하되, 구체적인 가격·한도 숫자는 계약이나 예산을 결정하기 전에 반드시 공급사 원문으로 재확인하세요.

자주 묻는 질문

Q. 무료로 쓸 수 있는 모델은 정확히 몇 개인가요?

비교표에 등록된 12개 모델 중 Gemini 1.5 Pro·1.5 Flash·2.0 Flash 3개만 API 무료 티어를 제공합니다. 나머지 9개(OpenAI 5개, Anthropic 3개, Gemini 2.0 Pro 1개)는 API 기준으로는 유료 전용입니다.

Q. 같은 Gemini인데 2.0 Pro만 유료인 이유는 결국 뭔가요?

공식적으로 발표된 단일 사유는 없지만, 무료 티어가 대체로 연산 비용이 낮은 경량 모델(Flash 계열)에 집중되고, 최상위·대용량 컨텍스트 모델(Pro)은 서버 비용 부담 때문에 유료로만 운영되는 경향이 업계 전반에서 관찰됩니다.

Q. ChatGPT나 Claude.ai를 무료로 쓰는 것과 API 무료 티어는 같은 건가요?

다릅니다. ChatGPT·Claude.ai 같은 채팅 웹앱의 무료 사용량은 API 무료 티어와 별개의 정책입니다. 이 비교표는 API 가격만 다루므로, 웹 채팅에서 느끼는 무료 경험과 표의 유료 표시가 다를 수 있습니다.

Q. 무료 티어에는 사용량 제한이 있나요?

네. 대체로 분당 요청 수·일일 요청 수 상한이 걸려 있으며, 이를 초과하면 요청이 거부되거나 유료 결제로 자동 전환됩니다. 실서비스 트래픽을 감당하려면 결국 유료 플랜 전환이 필요한 경우가 많습니다.
