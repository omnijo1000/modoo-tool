구글은 2009년부터 keywords 메타태그를 안 본다

가이드 · 2026.08.21 최종 확인

많은 사람이 여전히 <meta name="keywords">를 채워 넣으면 검색 순위에 도움이 될 거라 믿습니다. 그러나 구글은 이미 17년 전에 이 태그를 랭킹 계산에서 완전히 제외했다고 공식 발표했습니다. 이 가이드는 그 발표의 배경, 왜 지금도 관행이 남아 있는지, 그리고 실제 순위에 영향을 주는 메타 요소가 무엇인지 구조적으로 정리합니다.

1. 2009년 9월, 구글이 실제로 발표한 내용

구글은 2009년 9월 웹마스터 센트럴 블로그에서 "Google does not use the keywords meta tag in web ranking"이라고 명시적으로 밝혔습니다. 즉 페이지 콘텐츠와 무관하게 keywords 태그에 아무리 정교한 키워드를 넣어도 검색 순위 계산 알고리즘에는 전혀 반영되지 않는다는 뜻입니다. Bing 역시 2011년경 유사한 입장을 공개적으로 밝히며, 두 주요 검색엔진 모두 이 태그를 랭킹 신호에서 배제했음을 확인했습니다.

2. 왜 이런 결정을 내렸는가: 스팸 신호로 악용된 역사

keywords 태그가 배제된 이유는 단순한 "무의미함"이 아니라 "악용 가능성" 때문이었습니다. 1990년대 후반~2000년대 초반, 검색엔진이 keywords 태그 내용을 실제로 랭킹에 반영하던 시절에는 페이지 내용과 무관한 인기 검색어를 keywords에 대량으로 채워 넣는 "키워드 스터핑(keyword stuffing)" 스팸이 광범위하게 퍼졌습니다. 사용자가 눈으로 볼 수 없는 이 필드는 검증이 어려웠고, 검색 결과 품질을 떨어뜨리는 주범이 되었습니다. 구글은 이런 조작 가능성이 있는 비가시적 신호를 아예 알고리즘에서 제거하는 방향을 택했습니다.

비교 예시: 실제 콘텐츠가 "초보자용 파이썬 튜토리얼"인 페이지에 keywords 태그로 "아이폰, 다이어트, 로또번호, 파이썬"을 넣어도 구글 검색 결과 순위에는 어떤 영향도 없습니다. 반면 같은 단어들을 본문·제목·헤딩에 부자연스럽게 반복하면 콘텐츠 품질 저하로 오히려 순위가 떨어질 수 있습니다.

3. 그런데도 여전히 채워 넣는 이유

구글·Bing이 무시한다고 해서 keywords 태그가 완전히 죽은 코드는 아닙니다. 일부 소규모·지역 검색엔진이나 사이트 내부 검색, 오래된 CMS 플러그인은 여전히 이 필드를 참고하는 경우가 있습니다. 또한 마케팅팀·클라이언트 관행상 "SEO 체크리스트에 있으니 채운다"는 관성도 큽니다. 실제로 메타태그 생성기도 keywords 입력값이 있으면 <meta name="keywords"> 태그를 여전히 생성합니다 — 코드상 if(keywords) lines.push(...) 형태로, 값이 비어 있으면 아예 생략되고 채워져 있을 때만 출력하는 선택적 옵션으로 남아 있습니다.

4. 그렇다면 실제 순위에 영향을 주는 메타 요소는 무엇인가

메타 요소랭킹 직접 영향실질 역할
title 태그있음검색어 관련성 판단의 핵심 신호
description 메타없음(간접적)검색결과 스니펫 텍스트, 클릭률(CTR)에 영향
keywords 메타없음2009년 이후 완전 무시(구글), 스팸 이력으로 배제
본문 콘텐츠있음실제 관련성·품질 판단의 핵심

즉 keywords에 쏟을 시간을 title 태그 최적화와 본문 콘텐츠 품질에 투자하는 것이 훨씬 효과적입니다. SEO 타이틀 생성기와 메타 디스크립션 생성기로 실제 영향을 주는 요소부터 점검하세요.

5. 그래도 keywords 태그를 채워야 하는 상황

  • 사내/조직 검색엔진(Elasticsearch, 사이트 내부 검색 등)이 이 필드를 실제로 인덱싱에 활용하는 경우
  • 레거시 CMS나 특정 지역 검색엔진이 여전히 참고하는 경우
  • 콘텐츠 관리 목적으로 태그·분류 체계를 메타데이터에 남겨두고 싶은 경우(SEO 목적이 아닌 내부 관리 목적)

이런 특수한 경우가 아니라면 keywords 태그 작성에 들이는 시간은 사실상 낭비이며, 메타태그 분석기로 현재 페이지의 실질적으로 유효한 메타 태그부터 점검하는 편이 낫습니다.

자주 묻는 질문

Q. keywords 태그를 넣으면 순위에 마이너스가 되나요?

아니요. 순위 계산에서 아예 무시되므로 플러스도 마이너스도 아닙니다. 다만 스팸성 키워드 나열이 다른 스팸 판단 신호와 결합되면 간접적으로 불이익이 있을 수 있다는 견해도 있어, 굳이 무의미하게 채우는 것을 권장하지 않습니다.

Q. 그럼 메타태그 생성기에서 keywords 필드는 왜 아직 있나요?

일부 소규모 검색엔진·내부 검색·레거시 시스템이 참고할 수 있고, 사용자가 원하면 선택적으로 채울 수 있도록 옵션으로 남겨둔 것입니다. 비워두면 태그 자체가 생성되지 않으므로 필수 항목은 아닙니다.

Q. description 메타태그도 랭킹에 직접 영향을 주나요?

아니요. description도 랭킹 알고리즘에 직접 반영되지는 않습니다. 다만 검색 결과에 노출되는 스니펫 문구로 쓰이기 때문에 클릭률(CTR)에 영향을 주고, 이는 장기적으로 트래픽에 영향을 미칩니다.

Q. 2009년 이전에는 keywords 태그가 실제로 순위에 영향을 줬나요?

검색엔진 초창기(1990년대~2000년대 초)에는 일부 검색엔진이 참고했습니다. 그러나 키워드 스터핑 스팸이 확산되면서 신뢰할 수 없는 신호로 판단돼 주요 검색엔진들이 순차적으로 배제했습니다.
