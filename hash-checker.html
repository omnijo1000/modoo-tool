Hash 체커

텍스트 SHA-256/SHA-512/SHA-1 해시 생성 및 검증

입력 텍스트
텍스트
알려진 해시

해시 체커란?

텍스트의 SHA-256, SHA-384, SHA-512, SHA-1 해시를 생성하고, 알려진 해시값과 비교 검증합니다. 이 도구는 브라우저 내장 Web Crypto API(crypto.subtle.digest)로 해시를 계산하는데, 이 API는 표준상 SHA-1·SHA-256·SHA-384·SHA-512만 지원하고 MD5는 지원하지 않습니다 — MD5 알고리즘 이름을 넘기면 브라우저가 오류를 던집니다. 따라서 이 도구로는 MD5 해시를 생성할 수 없으며, MD5가 필요하다면 별도의 MD5 전용 도구를 이용해야 합니다.

자주 묻는 질문

이 도구로 MD5 해시도 만들 수 있나요?

아니요. 이 도구가 사용하는 Web Crypto API의 crypto.subtle.digest()는 SHA-1, SHA-256, SHA-384, SHA-512만 지원하도록 브라우저 표준에 정해져 있어 MD5 알고리즘 자체를 지원하지 않습니다. MD5 문자열을 넘기면 브라우저가 지원하지 않는다는 오류를 발생시킵니다. MD5 해시가 필요하면 별도의 MD5 계산 도구를 사용하세요.

실제로 생성 가능한 해시 알고리즘은 무엇인가요?

SHA-256, SHA-384, SHA-512, SHA-1 네 가지입니다. 텍스트를 입력하면 이 네 알고리즘의 해시값이 한 번에 모두 계산되어 표시됩니다.

SHA-256과 SHA-512의 차이는?

SHA-256은 256비트(64자리 16진수) 해시를, SHA-512는 512비트(128자리 16진수) 해시를 생성합니다. SHA-512가 이론적으로 더 큰 출력 공간을 가지지만, 일반적인 무결성 검증 목적으로는 SHA-256으로도 충분히 안전합니다.

해시는 왜 단방향인가요?

해시 함수는 임의 크기의 입력을 고정 크기 출력으로 변환하도록 설계되어 있고, 그 역방향 연산(해시값에서 원본을 복원하는 것)이 계산적으로 불가능하도록 만들어졌기 때문입니다.

동일한 텍스트는 항상 같은 해시를 생성하나요?

네. 해시 함수는 결정론적이므로, 완전히 같은 입력(공백 하나까지 포함)은 항상 같은 해시값을 만들어냅니다.

파일 해시 검증이란 무엇인가요?

다운로드한 파일이 손상되거나 변조되지 않았는지 확인하기 위해, 배포자가 공개한 해시값과 직접 계산한 해시값을 비교하는 절차입니다. 단, 이 도구는 텍스트 입력만 지원하므로 파일 자체를 검증하려면 파일 내용을 텍스트로 변환하거나 별도의 파일 해시 도구가 필요합니다.

서버로 텍스트가 전송되나요?

아니요. Web Crypto API 호출을 포함한 모든 계산이 브라우저 안에서만 실행되며, 입력한 텍스트는 어디로도 전송되지 않습니다.

비밀번호 저장에 이 도구의 해시를 사용해도 되나요?

권장하지 않습니다. SHA 계열은 계산 속도가 빨라 무차별 대입 공격에 취약하므로 비밀번호 저장에는 적합하지 않습니다. bcrypt, Argon2, PBKDF2처럼 의도적으로 느리게 설계된 키 스트레칭 알고리즘을 사용하세요.
