PDF 워터마크 추가

PDF에 워터마크를 추가하면 문서가 원본이 아닌 복사본이거나 특정 용도(초안, 대외비, 견본 등)임을 시각적으로 표시할 수 있습니다. 이 도구는 pdf-lib로 각 페이지 위에 지정한 텍스트를 그려 넣는 방식으로 동작하며, PDF 규격에 포함된 14개 기본 내장 폰트 중 하나인 Helvetica Bold를 사용합니다. 이 폰트는 별도 파일을 임베드하지 않아도 모든 PDF 뷰어에서 표시되지만, 라틴 알파벳·숫자·기호만 지원하고 한글·한자·가나 등 비ASCII 문자 글리프는 포함하지 않습니다. 계약서 초안 표시, 샘플 이미지 저작권 표기, 사내 문서 배포 관리 등에 활용됩니다.

자주 묻는 질문

한글 워터마크가 지원되나요?

지원되지 않습니다. 이 도구가 사용하는 PDF 표준 내장 폰트(Helvetica)는 라틴 문자셋만 포함하고 있어 한글을 입력하면 빈 사각형(□)이나 깨진 문자로 표시됩니다. 한글 워터마크가 꼭 필요하다면 CONFIDENTIAL, DRAFT, SAMPLE처럼 영문 단어를 사용하는 것을 권장합니다.

파일이 서버로 전송되나요?

아니요. pdf-lib가 브라우저 메모리 안에서 PDF를 직접 불러와 텍스트를 그려 넣고 다시 저장하므로 파일이 외부로 전송되지 않습니다.

워터마크를 특정 페이지에만 적용할 수 있나요?

현재 버전은 모든 페이지에 동일하게 적용하는 방식만 지원합니다. 표지만 제외하거나 특정 구간에만 넣고 싶다면, 워터마크 적용 후 해당 페이지를 별도로 원본과 교체하는 방식을 사용해야 합니다.

워터마크를 제거할 수 있나요?

이 도구 자체에는 제거 기능이 없습니다. 워터마크는 페이지 콘텐츠 스트림에 실제 텍스트 객체로 그려지기 때문에, 제거하려면 PDF 편집기로 해당 텍스트 객체를 직접 찾아 삭제해야 합니다. 워터마크를 적용하기 전 원본 파일을 따로 보관해두는 것이 가장 확실한 방법입니다.

투명도를 0%로 설정하면?

워터마크 텍스트의 알파값이 0이 되어 화면과 인쇄물 모두에서 보이지 않게 됩니다. 완전히 숨기는 용도가 아니라면 20~40% 정도의 투명도가 원본 내용을 가리지 않으면서도 워터마크를 식별할 수 있는 적정 범위입니다.

암호화된 PDF도 처리되나요?

아니요. 열람 암호가 걸린 PDF는 pdf-lib가 파일을 열 수 없어 처리할 수 없습니다. PDF 암호 해제 도구로 먼저 잠금을 해제해야 합니다.

이미지 워터마크는 지원하나요?

현재는 텍스트 워터마크만 지원합니다. 로고나 도장 이미지를 삽입하려면 pdf-lib의 embedPng/embedJpg 기능이 필요한데, 이는 향후 별도 도구로 제공할 계획입니다.

모바일에서도 사용 가능한가요?

네, pdf-lib가 표준 브라우저 API(File, ArrayBuffer, Blob)만 사용하므로 별도 앱 설치 없이 최신 모바일 브라우저(Chrome, Safari 등)에서도 정상 동작합니다.
