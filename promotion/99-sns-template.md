# Handoff: modoohub 카드뉴스 디자인 시스템

## Overview
종합소득세 환급금 계산기 홍보용 인스타그램 피드 카드뉴스(1080x1350, 4:5) 디자인. 다크 글래스모피즘 + 네이비-골드 브랜드 톤의 카드뉴스 시스템으로, 콘텐츠 성격별 5가지 레이아웃 타입(A~E)을 정의함.

## About the Design Files
이 폴더의 HTML 파일은 **디자인 레퍼런스**입니다 — 최종 룩앤필과 인터랙션을 보여주는 프로토타입이며, 그대로 복사해 쓰는 프로덕션 코드가 아닙니다. 실제 작업 시에는 대상 코드베이스(React/Vue/Next 등 이미 쓰는 스택, 없다면 이미지 카드뉴스 생성에 적합한 스택 선택)에서 이 디자인을 동일하게 재현하면 됩니다. 각 카드는 정적 1080x1350 이미지로 최종 출력(캡처/렌더링)되는 것이 목적입니다.

## Fidelity
**High-fidelity.** 색상, 타이포, 간격, 레이아웃이 최종안에 가까운 하이파이 목업입니다. 정확한 값대로 재현해야 합니다.

## Files
- `card-news-typeA.html` — Type A 샘플: 종합소득세 환급금 5장 캐러셀 (다크 글래스 수치 강조형)
- `card-news-typeB-E.html` — Type B~E 샘플 4종 (명세서형 / 경고형 / VS비교형 / 클린라이트형)
- `assets/modoohub-logo-icon.png` — 브랜드 로고 (네이비→골드 그라데이션 M 마크)

## Design System (고정 요소)
- **폰트**: Pretendard (없을 경우 Noto Sans KR로 대체). 한글 가독성 우선, 숫자는 필요 시 monospace.
- **캔버스**: 1080×1350 (4:5), 프리뷰 기준 432×540 (동일 비율 스케일)
- **배경**: `#0B0F19` 딥 다크 네이비 + 미세 모눈 그리드 (`background-size: 20px 20px`, opacity ~0.05)
- **글래스 카드**: `background: rgba(255,255,255,0.04)`, `backdrop-filter: blur(16px)`, `border: 1px solid rgba(255,255,255,0.1)`
- **글로우 레이어**: blur(80~90px) 원형 블롭, 상단 우측 골드(`#f59e0b`, opacity ~0.3) + 하단 좌측 네이비(`#1e3a8a`, opacity ~0.4)
- **브랜드 액센트 컬러**: 골드/앰버 그라데이션 `linear-gradient(90deg, #fcd34d, #f59e0b)` — 숫자 강조, 뱃지, 체크아이콘 등 포인트에만 사용 (남발 금지)
- **본문 텍스트**: 타이틀 `#f8fafc`, 서브텍스트 `#94a3b8`/`#cbd5e1`
- **헤더**: 좌측 로고 아이콘(18~20px) + "MODOO HUB" 워드마크(HUB는 골드), 우측에 타입 뱃지 또는 `01/05` 인디케이터
- **경고/알럿 전용 컬러(Type C)**: 레드 틴트 `#dc2626`/`#7f1d1d` 글로우, 텍스트 `#fecaca`/`#fca5a5`, 아이콘 `#f87171`
- **비교형(Type D) 분할 컬러**: 좌=네이비(`rgba(30,58,138,0.15)`, 텍스트 `#93c5fd`), 우=골드(`rgba(245,158,11,0.1)`, 텍스트 `#fbbf24`)
- **클린 라이트(Type E)**: 배경 `#f7f5f0`, 글래스 카드 `rgba(255,255,255,0.7)`, 골드 포인트만 유지, 텍스트는 다크(`#0B0F19`/`#57534e`)

## Layout Types
| Type | 용도 | 핵심 구조 |
|---|---|---|
| A. 다크 글래스 수치 강조형 | 종합소득세/환급금 등 '큰 숫자'가 핵심 | 대형 골드 그라데이션 숫자 + 헤드라인, 5장 캐러셀(체크리스트/경고/표/CTA) |
| B. 영수증/명세서 UI형 | 실수령액, 4대보험 공제 등 상세 내역 | 점선 구분선 명세서 카드, monospace 숫자, 합계 골드 강조 |
| C. 딥 레드 경고형 | 실수, 법 개정, 마감 임박 | 레드 틴트 배경 + 경고 아이콘 + 강조 박스 |
| D. 좌우 비교/VS형 | 두 옵션 비교 | 중앙 VS 원, 좌(네이비)/우(골드) 분할 카드 |
| E. 클린 라이트형 | BMI, D-Day 등 피드 환기용 | 라이트 배경, 원형 게이지/카드형 결과 표시 |

## Interactions & Behavior (Type A 캐러셀)
- 하단 이전/다음 버튼 클릭 시 슬라이드 전환 (트랜지션 없이 즉시 스위칭)
- 상단 인디케이터 `01/05` 형식, 하단 도트 인디케이터(활성 슬라이드는 폭 20px 골드 pill, 비활성은 6px 회색 dot)
- 첫 슬라이드에서 이전 버튼, 마지막 슬라이드에서 다음 버튼 비활성화(아이콘 색 `#475569`로 톤다운)

## Assets
- 로고: 사용자 제공 `modoohub-logo-icon.png` (네이비-골드 그라데이션 M 마크). 다크 배경에는 원본 그대로, 라이트 배경(Type E)에도 동일 파일 사용 가능(투명 배경 없을 경우 확인 필요).
- 아이콘: 별도 아이콘 세트 없이 인라인 SVG(체크, 경고 삼각형, 화살표)로 구현 — 재현 시 lucide-react 등 아이콘 라이브러리로 대체 가능.
