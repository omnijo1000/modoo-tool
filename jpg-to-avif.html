JPG to AVIF 변환기

JPG, PNG 이미지를 AVIF(AV1 Image File Format) 형식으로 변환합니다. 페이지를 열면 1×1 픽셀 캔버스로 canvas.toBlob(..., 'image/avif')를 실제로 호출해보고 결과 Blob이 존재하는지 확인하는 방식으로 브라우저의 AVIF 인코딩 지원 여부를 실시간으로 감지합니다(단순 브라우저 버전 문자열 비교가 아닌 실제 기능 테스트). PNG의 투명 배경은 캔버스가 기본적으로 투명하게 초기화되고 AVIF 자체도 알파 채널을 지원하므로 변환 후에도 그대로 유지됩니다. Canvas API를 사용해 브라우저에서 직접 변환하므로 파일이 서버에 업로드되지 않습니다.

자주 묻는 질문

AVIF 형식이란?

AV1 Image File Format으로, Netflix가 주도한 AOMedia에서 개발한 차세대 이미지 형식입니다. 탁월한 압축률과 화질을 제공합니다.

어떤 브라우저에서 AVIF 인코딩이 가능한가요?

Chrome 85+, Firefox 93+, Safari 16+에서 Canvas API를 통한 AVIF 인코딩이 지원됩니다. 이 페이지는 실제로 1픽셀짜리 캔버스를 AVIF로 인코딩해보고 성공 여부로 지원 여부를 판단하므로, 목록에 없는 브라우저라도 지원하면 자동으로 인식됩니다.

AVIF가 WebP보다 나은가요?

일반적으로 AVIF가 WebP보다 약 20% 더 작은 파일 크기를 제공하지만, 인코딩 속도는 느릴 수 있습니다.

변환 시 원본 품질이 유지되나요?

품질 슬라이더로 출력 품질을 조정할 수 있습니다. 80% 이상에서는 육안으로 차이가 거의 없습니다. PNG의 투명 배경은 AVIF도 알파 채널을 지원하므로 손실 없이 그대로 유지됩니다.

파일이 서버에 업로드되나요?

아니요. 모든 변환이 브라우저 로컬에서 처리됩니다.

AVIF를 지원하지 않는 브라우저를 위한 대안은?

Chrome 85+, Firefox 93+, Safari 16+ 이상으로 업그레이드하거나, WebP 형식을 대안으로 사용하세요.

AVIF 파일을 열 수 없어요.

최신 Chrome, Firefox, Safari, Edge에서 AVIF를 지원합니다. Windows 사진 뷰어는 아직 지원하지 않을 수 있습니다.

여러 파일을 한 번에 변환할 수 있나요?

예, 여러 파일을 선택하거나 드래그하면 순차적으로 변환됩니다.
